# Air Exasperato crafting source audit

Read-only source: disabled LBC datapack at `E:/servers_mew/cringe1_21_4_skywars/world/datapacksdisabled/LBC/data/lbc`.

## Recipe and restrictions

- Ground crafting is dispatched by `function/other/craft_ground.mcfunction`: a dropped item carrying `custom_data.stair:1` checks for a separate dropped item within 1 block carrying `custom_data.exoperso:1`, then calls `other/sauvojen_tuntija/crafted_exasperoso`. The two markers are the only recipe predicates: there is no `upgraded` exclusion, so an upgraded Air staff donor (`stair:1,upgraded:1`) qualifies. There is no explicit count restriction.
- Inventory crafting is dispatched by `function/other/craft/inventory_craft_check.mcfunction` using any two crafting-grid slots containing `stair:1` and `exoperso:1`; again no `upgraded` exclusion or count condition. `crafted_exasperoso_inv.mcfunction` reduces each matching marker stack in the four 2x2 slots by one. It checks/reduces both marker types independently, so it consumes one of each for ordinary distinct ingredients.
- Ground result handler spawns the result and kills the nearest dropped `exoperso:1` item entity without reducing its stack. This deletes the whole donor item entity if it contained multiple items; the stair donor entity (`@s`) is also killed. This is source behavior and an apparent stack-consumption inconsistency with inventory crafting.
- Both handlers spawn exactly one result via loot table `loot_table/tuntijaa_air_exasperoso.json`, with enchantment-table sound and gold dust particle effects. Inventory handler leaves crafting ingredients present until this function runs, then decrements each matching stack.

## Result identity and port comparison

`tuntijaa_air_exasperoso.json` creates one `minecraft:carrot_on_a_stick`, model `lbc:exasperato`, tooltip style `lbc:tier_s`, dark-red translated name `exasperato_wand`, aqua translated type/staff and mana lines, white translated lore lines `.1` and `.2`, and custom data `{transformable:1,staff:1,magicwand:1,exasperato_wand:1}`. This matches the current ported result identity and presentation in `src/main/resources/data/lbc/loot_table/ported/exasperato_wand.json` (registered item `skywars2:exasperato_wand`). The legacy crafting output does not set `craftusable:1`.

## Separate Exoperso donor scope (summary only)

The consumed `exoperso:1` donor is a separate, currently unported wand (not the already-ported Exasperato result). Its source item is in `loot_table/transformables_staff.json`; normal/upgraded casts are selected by `workingitems/spell1.mcfunction` and `spell1_upgraded.mcfunction` (also left-hand dispatch in `_left` variants), gated by mana and `stopper_magic`. Cast entry points are `exoperso_pre` / `exoperso_upgraded_pre`, charging 25,000 / 10,000 mana and spawning owner-tagged raycast markers. `exoperso2` / `exoperso2_upg`, `exopersorcall`, and particle functions implement the ray flight and collision. Impact calls `exopersoexplode`: it summons 30 invulnerable, instant-fuse creepers with explosion radius 20 in a large multi-level formation, plus sounds/particles; a delayed check awards the staff advancement if this cast is credited with killing the last active player in a match of at least three. `killed_by_exoperso.json` tracks player kills by tagged creepers. The normal wand also increments a held-wand score toward Academy upgrade readiness. Related source includes `workingitems/exoperso*.mcfunction`, `workingitems/spell1*.mcfunction`, `advancement/killed_by_exoperso.json`, `advancement/true_advancements/staffs/exoperso.json`, `advancement/true_advancements/legends/academy/exoperso.json`, and `function/other/magic_academy/{upgrade,can_upgrade}/exoperso.mcfunction`.

Porting Exoperso itself is a substantial separate mechanic: wand item/dispatch and Academy integration, mana/cast state, owner/team attribution, long-lived raycast and particle behavior, large explosion formation, kill/last-player advancement accounting, cleanup on death/leave, and asset/sound coverage. It is materially larger than adding this recipe to the already-ported Exasperato wand. AGENTS.md already settles the migration: native 2x2/3x3 output slots, exactly one of each ingredient, no extra ingredients, no ground scanners or dropped crafting results. The legacy ground stack-deletion quirk is not preserved.
