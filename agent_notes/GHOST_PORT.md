# Порт набора LBC10 «Призрак»

Текущий порт набора описан в [аудите исходника](GHOST_SOURCE_AUDIT.md); общий статус проверок сервера ведётся в [SERVER_TESTS.md](../SERVER_TESTS.md).

`import_lbc_loadouts.py` добавляет набор 10 в нативный импорт, `processResources` включает datapack loot table, а каталог `lbc_loadouts.json` связывает набор с `lbc:kit/ghost` и сохраняет gate `lbc:true_advancements/armor/phantom`. Выдача выполняется существующим `LbcLoadouts`; для набора не добавлялись отдельные Java обработчики или постоянный тик-опрос.

Порт сохраняет исходный gate. Прогресс достижения phantom читается нативным реестром достижений, а явный административный импорт unlock также доступен. При этом полноценный движок phantom armor и автоматическое получение gate в обычной игре пока не перенесены. Поэтому наличие gate в каталоге не означает, что путь его разблокировки уже реализован целиком.

Оформление повторно использует существующие ключи ресурс-пака: имя `ghost_potion` и карточные ключи `lbckit.9` / `lore.lbckit.9.*`; новых переводов для набора не требуется. У зелья сохранена стандартная модель `minecraft:splash_potion` и отсутствует дополнительный lore; карточка использует исходную модель `lbc:windik`. Имя зелья без курсива, цвет `14737663`, максимум стака 4. Сам пользовательский ресурс-пак остаётся только источником чтения.

Живые проверки прошли на изолированном Fabric 26.3 сервере: `ghost-menu`, `ghost` и `ghost-cleanup` в `tools/smoke_lbc_loadouts.py`. Подтверждены нативный `effects_changed` для high invisibility (II, но не I), splash с уменьшением длительности по расстоянию, исключение наблюдателя Adventure, истечение эффектов после 100 тиков, однократная выдача при респауне и очистка после остановки матча. Для проверки меню прогресс phantom помечается fixture вручную: получение этого достижения обычным убийством в фантомной броне ещё не проверялось. Результаты и точный SHA сборки — [SERVER_TESTS.md](../SERVER_TESTS.md).
