# Blind Wand: импорт ресурсов

Импортированы `skywars2:blind_wand` и `skywars2:academy_blind_wand` из одного исходного entry: [loot_table/sauvojen_tuntija_blind.json](E:/servers_mew/cringe1_21_4_skywars/world/datapacksdisabled/LBC/data/lbc/loot_table/sauvojen_tuntija_blind.json). Запуск импортёра: `python tools/import_lbc_wands.py --blind`.

Оба варианта сохраняют авторское имя `sauvojen_wand_blind`, item model `lbc:st/blind`, tooltip tier `lbc:tier_b` и полное исходное lore с форматированием: `type`, `staff`, scoreboard `stblind_wand_mana_use` (`lbc.math`), `mana_on_activate`, ключи `sauvojen_wand_blind.lore.1`–`.4`. Custom data обычного жезла сохраняет `{craftusable:1,transformable:1,staff:1,magicwand:1,stblind:1}`. RP item definition [st/blind.json](<C:/Users/yarik_temp/AppData/Roaming/FreesmLauncher/instances/26.3(1)/minecraft/resourcepacks/all_in_one_1.21.8/assets/lbc/items/st/blind.json>) указывает на модель [models/item/st/blind.json](<C:/Users/yarik_temp/AppData/Roaming/FreesmLauncher/instances/26.3(1)/minecraft/resourcepacks/all_in_one_1.21.8/assets/lbc/models/item/st/blind.json>). Переводы исходных name/lore находятся в `assets/minecraft/lang/ru_ru.json` и `en_us.json` под теми же ключами.

Стоимость каста — 250 маны: [function/config.mcfunction](E:/servers_mew/cringe1_21_4_skywars/world/datapacksdisabled/LBC/data/lbc/function/config.mcfunction#L52) задаёт `stblind_wand_mana_use=250`.

Academy payload следует полному source chain. Общий [interacted_upgrade.mcfunction](E:/servers_mew/cringe1_21_4_skywars/world/datapacksdisabled/LBC/data/lbc/function/other/magic_academy/interacted_upgrade.mcfunction) выставляет `upgraded:1`, `mode:1` и применяет `lbc:add_upgrade_desc`; последний добавляет lore key `upgraded_item`. Затем [upgrade/stblind.mcfunction](E:/servers_mew/cringe1_21_4_skywars/world/datapacksdisabled/LBC/data/lbc/function/other/magic_academy/upgrade/stblind.mcfunction) применяет `lbc:tiers/b`. Импорт Academy сохраняет исходный предметный payload, добавляет общие флаги `upgradable:0`, `upgrade_available:1`, `upgraded:1`, `mode:1`, source lore `upgraded_item` и source tier modifier `tiers/b`. Переводы `upgrade_succesful_stblind`, `upgrade_condition_stblind` и `upgraded_item` сверены в RP RU/EN. Успешное сообщение описывает четыре открываемых режима: стандартный, phantom, gatlingator и rain; в item custom data source-chain marker режима — `mode:1`.

Результаты: [blind_wand.json](../src/main/resources/data/lbc/loot_table/ported/blind_wand.json), [academy_blind_wand.json](../src/main/resources/data/lbc/loot_table/ported/academy_blind_wand.json). В Academy entry исходные пять modifier payload сохранены, затем следуют common `add_upgrade_desc` и `tiers/b`.
