# Soulless Academy native checks

`SoullessAcademyChecks.run/tick` implements the asynchronous `soulless-academy`
suite. Consecutive Academy callbacks cross real server ticks, preserving the
production duplicate-click guard. This is a focused extension to the separate
`soulhunter` regression suite, which retains the six metasola mechanics,
ordinary ghost attributes, conversion, geometry, attribution and actual-stop
checks.

The new suite uses native loot leaves and `ServerPlayer.gameMode.useItem` for
native items, and the shared wand callback for legacy vanilla carriers. It
checks native Academy identity/class, source flags/model/A tier, all fourteen
source lore rows plus the green upgrade marker; both used hands; legacy/native
mode selection; independent two-hand selectors and configured offhand rejection.
Mode selection is free at zero mana. Mode 1 shares WILD additive ghosting while
respecting Greed and technical roles. Mode 2 rejects1499, debits1500 without a
refund, and creates one existing six-way metasola loot item at the caster's
feet without deploying a field. Actual two-hand input independently debits3000
for two rewards. Mixed hands cannot borrow an ordinary trial from another hand.

The ordinary trial is assigned by the native Academy Interaction callback.
Unpaid meditation has no readiness or summons. Paid meditation in either hand,
using a native item or legacy carrier, creates exactly sixteen native hostile
Vex at the source +1.6Y position and immediately marks only the used stack ready.
The Vex retain native AI and eligibility to attack the caster and teammates.
The meditation branch creates no ghost status, ghost-reward helper or WindCharge.
Unload and explicit owner invalidation retire these helpers quietly. A real
antimagic marker prevents a cast but preserves already summoned ordinary Vex;
Time Stop retains the frozen helpers. A real grounded Academy
token builds the final school from the native template. The real promotion
callback changes the ready ordinary wand into Academy Soulless, applies source
mode1/A tier/full presentation and consumes that single-use school.

Fixture ownership is explicit. It first requires empty Soulless/Academy services,
normal time, two active players with closed menus, no borrowed frost/combat state,
resident school columns and no unrelated entities within its effect sphere.
It snapshots/restores both complete player states, public profile/config fields,
teams, input flags, affected extra mana scores, configured wand cost, Academy
click timestamps, native item/custom/entity statistics and advancement criteria.
The school terrain and its pre-existing block/fluid ticks are restored exactly.
Only owned entities and loot generated by this fixture are removed. The fixture
does not advance game time, change the source server or edit the author RP.

The optional `soulless-academy-stop-probe` and `soulless-academy-cleanup` pair
retains sixteen trial Vex across an actual match stop and checks epoch invalidation
and quiet removal. Run its setup before other probes borrow Time Stop pauses.
The player snapshot is restored immediately during setup; only the helper list
and epoch survive until cleanup, avoiding later restoration of stale player tags.

Compilation/runtime qualification is recorded by the coordinating task after
the final artifact is built. These checks qualify native dispatch/state, not
client pixels, disk restart, real disconnect or peak-load behavior.
