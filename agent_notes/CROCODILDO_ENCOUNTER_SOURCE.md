## Port recommendations and author decisions

Bounded implementation is technically possible with existing encounter/trigger structure (`J/LbcHelicopterEncounter.java`, `J/LbcHelicopterTriggerItem.java`), native loot conversion, damage-cause routing and lifecycle cleanup. Reuse `J/NuclearVisuals.java:show` for the approved shader visual, and study `J/LbcExasperato.java` budgeted blast queue/protectedBlast plus arena edit journaling for destruction. Its 32-blast Nuke payload is **not** the source 24-blast Crocodildo payload. Reward readiness requires a native nuke egg behavior or an explicit author-approved substitute; returning the raw spawn egg is not a complete port.

Resolve before claiming source fidelity:

1. Turtle max-health100200 but missing initial Health is a real source defect risk: do not assume it starts at100200. Intended contract appears to be200 effective health above100000, but author should confirm native200 HP initialization and lethal/overkill handling.
2. Confirm retaining destructive 12-template/24-radius25 explosion payload, extreme Wither30, and broad local nonplayer kill, versus correcting collateral damage. Terrain operations require bounded queueing; source volume must not run synchronously.
3. Confirm ordinary rewarded death under mechanism suppression, analogous to author-approved Helicopter, and whether bomb mechanics pause with the encounter. Source independently scheduled5s drops continue during time stop while movement/pig detonation pauses.
4. Global bar/music collide across concurrent bosses; recommend per-encounter bar and reference-counted shared music, explicit pair ownership, one reward per true death, and quiet cleanup for unload/end. Preserve source cadence separately from this safety fix.

Mandatory existing user policy: retain direct and delayed kill attribution; source lacks it. Hostile autonomous boss/bomb causes should remain real NPC causes (rather than assigning token dropper), consistently with the qualified Helicopter encounter. Source team assignment is absent; temporary nodamage cleanup also excludes all turtles, so do not transplant its global temporary-tag side effects.
