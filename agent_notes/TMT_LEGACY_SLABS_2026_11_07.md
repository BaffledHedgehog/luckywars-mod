## Native behavior

`BLOOD` is a genuine acacia-slab BlockItem, `CUM` a genuine birch-slab BlockItem.
The canonical prototype reader retains source name/lore/model/tier/custom data.
Vanilla placement owns actual geometry, permissions, waterlogging, statistics and
one debit of the used hand. Blood's advancement matches its flag regardless of
carrier; white additionally requires birch (including its canonical native item).
TMT's selected native carrier is checked inside its existing private source scope.

Successful placement submits exactly 1000 original eye samples (999 advances of
0.025) to the existing Exasperato discrete-ray queue. First nonair creates the
authored centered marker. Its frame is submitted to the existing fair Stonekivi
queue; there is no second global terrain scheduler or arbitrary actor/work cap.
Source `blood_slabbed`/`bloody_slabby` tags remain authoritative. Owned writes use
the existing terrain journal/provenance/Bedwars guard. Unloaded cells are not loaded.

Blood emits the original six neighboring infection nodes, exact 32-way palette
(including the duplicate nether_bricks weight), 30% nearby opposing-score node
acceleration, and 5% unobstructed random-mob branch. That branch uses native entity
factories, the existing Mom family owner, original arrow-area damage/immune tag,
audio/particles and eight diagonal nodes. The original score predicate tests
actual marker `team_number` scores; this implementation does not invent marker
teams from their authors. Missing scores retain the predicate's unequal behavior.

White retains distinct down and central states: double downward slabs, success-
dependent continuation, unconditional four double slabs on landing, then bottom
slabs with four air-only horizontal producers or a downward branch.

Blood has `magic`; white intentionally does not. Blood producer suppression is
checked at its physical marker; placement retains the common physical input guards.
Both pause with TimeStop and retire at epoch/match teardown. Existing explicit
source authority/exclusions are retained. Ordinary accepted sources use the first
physical marker as emitter, retaining creator/WILD cause so creator/allies can be
affected. Descendants retain that immutable source even after the original marker
is gone. Native mob children bind that same source and epoch.
