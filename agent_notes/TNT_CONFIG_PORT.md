# Настройка защиты TNT — 20 октября 2026

`GameConfig.tntProtection` сохраняется в `config/luckywars/game.json`:
0/1/2/3/4/5 означают уменьшение урона TNT на 0/20/40/60/80/100%.
Значение по умолчанию — **4**, как `#tnt_resist` в исходном
`swarogskywars/data/swrg/function/core/default_settings.mcfunction:12`.
Отсутствующее поле старого JSON получает этот default; load/save ограничивают
диапазон 0..5, `/settings tntProtection <0..5>` отклоняет выход за диапазон.

Восстановлена кнопка исходного слота 12 страницы 1000. Цикл 0→1→2→3→4→5→0
использует существующий `GameMenus.change`: проверка лобби и
`GameController.allowMatchControl`, сохранение, перерисовка. Reset возвращает 4.
Команда использует прежнюю проверку OP 2+ / консоли и лобби.

Исходные `gui/select/1000.mcfunction:47..49` и `gui/page/1000-lang.mcfunction:72..76`
поддерживали только 0..4. Уровень 5 добавлен для полного иммунитета TNT.
Варианты 0..4 используют прежние подготовленные компоненты/translate keys.
Новый уровень использует `skywars2.gui.source.page1000.s12-5.part0` с тем же
белым цветом и `italic=false`, имя «Урон от динамита - защита 5».
Оба языка исходного RP содержат русские имена уровней 1..4, поэтому новый
ключ в RU/EN сохраняет этот дизайн. Новый ключ добавлен в языки мода и
`resourcepack_template/assets/minecraft/lang/{ru_ru,en_us}.json`.
Ключ template нужно **объединить** с соответствующим языком пака, не заменять
его lang JSON целиком. Реальный `all_in_one_1.21.8` только прочитан.

Общий `LbcDamage.protectedTntDamage` читает конфиг после расчёта сложности
Minecraft, до брони и настоящих эффектов. Resistance от конфига не выдаётся.
Полная защита отменяет нулевой hurt до запуска его реакций/cooldown;
нативный explosion knockback и разрушение блоков рассчитываются независимо.
Прямые источники исходного fuse=0 помечаются отдельно и обходят только конфиг.
