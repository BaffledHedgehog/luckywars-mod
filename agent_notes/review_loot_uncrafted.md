# Независимая строгая сверка uncrafted loot

Проверил все 625 источников из research_jobs.json: 624 корректных JSON loot tables и один файл uncrafted/tmp.tmp с черновыми командами. Черновик описан отдельно и не трактуется как таблица или исполняемая функция.

Структурный аудит 624 таблиц сопоставил каждую с её секцией основной заметки: все 1 041 pools и 1 059 прямых entries присутствуют в ожидаемом количестве. Проверены 412 функций set_count; для каждого пула совпадает число изменений с суммой entry- и pool-level functions, и отдельно сверено отсутствие/количество table-level functions. Все 1 453 числовых значения JSON встречаются в секции своей таблицы. Это подтверждает конкретные количества, в том числе рецепты с несколькими pool: каждый такой pool генерирует свой независимый результат, а не единый выходной комплект.

Проверены ссылки на вложенные таблицы: в этих 624 JSON их нет. Поля set_count записаны точными числами/диапазонами; текст исходной основы выхода и последовательность function payload приведены в каждой карточке. Для переноса важно учитывать не только имя файла-рецепта, но каждый pool отдельно и фактические количества set_count; источники не запускались. Поиск ссылок/команд к таблицам остаётся отражён в самих карточках как буквальные callers, это не предположение о доступности рецепта в игре.

Строгие проверки: JSON parse; соответствие source → точный section heading; совпадение количества pools/entries; совпадение количества entry/pool/table functions; numeric fields в соответствующих секциях; проверка полного упорядоченного manifest.
