## Работа с изменениями

- Ресурс-пак — источник для чтения и сверки. Агент не изменяет, не удаляет,
  не перемещает его файлы и не запускает генераторы с записью в эту папку.
- Новые необходимые ресурсы и изменения готовятся в
  `E:/servers_mew/skywars2_last/luckywars-mod/resourcepack_template/` с путями
  относительно корня пака, например `assets/lbc/lang/ru_ru.json`.
  Папка создаётся только когда есть реальные изменения для передачи пользователю.
  Шаблон содержит только необходимые изменения, без полной копии исходного пака.
  Для JSON с отдельными добавлениями явно указывается, что их нужно объединить
  с существующим файлом, а не заменить им весь файл.
- Пользователь сам применяет изменения в исходном паке и удаляет перенесённые
  шаблоны из проекта. После этого актуальным источником служит ресурс-пак.
  Перед новой правкой перечитывается соответствующий файл пака: удалённый
  template не означает потерю ресурсов и не является поводом восстановить его.
- Существующие translate keys переиспользуются с прежними идентификаторами.
  Не создаются новые ключи с другим префиксом для уже существующего текста,
  повторные записи ключа в JSON или копии готовых переводов в моде/template.
  Если ключ уже есть с нужным значением, добавления для него не требуются.
  Если нужно изменить существующий ключ, шаблон содержит одну явную правку
  этого ключа, применяемую пользователем, а не вторую запись или новый псевдоним.

## Как переносить предметы

Для каждого предмета сверяются исходная выдача/loot table/item modifier
датапака и соответствующие переводы и ресурсы этого пака. Сохраняются:

- Исходные `custom_name`/`item_name`, translate keys и их аргументы;
  буквальные части текста, вложенные компоненты и их порядок.
- Точные значения переводов каждого имеющегося языка: регистр, символы,
  пробелы и переносы. Текст не переписывается своими словами при переносе.
- Lore: количество и порядок строк, пустые строки и отдельные участки
  форматирования внутри каждой строки.
- Цвета, включая RGB, `italic`, `bold`, `underlined`, `strikethrough`,
  `obfuscated`, `font` и остальные заданные свойства компонентов.
  Сохраняется наследование оформления; отсутствие свойства не заменяется
  автоматически на `false` или оформление по умолчанию библиотеки GUI.
- Ссылки на модели и шрифты, влияющие на исходный вид предмета и его текста.

При передаче текста клиенту используются переводимые компоненты с прежними
аргументами и стилями; текст не превращается заранее в строку через `getString()`.
Смена языка или загрузчика сервера сама по себе не разрешает менять дизайн.
Если точный перенос пока не подтверждён, это отмечается как незавершённая сверка.
