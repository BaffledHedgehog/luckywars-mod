# Первые жезлы: Tiny Fire и Tiny Blind

Реализован ограниченный срез: два малых Sauvojen-жезла, их общие cast-бонусы,
два связанных тринкета и личный таймер `nomagic`. Адресный прогон прошёл за
51,32 с (четыре уникальные check-группы, один матч); полный — за 320,51 с
(21 матч, 59 сценариев / 63 уникальные check-группы). Проверенный JAR установлен,
основной сервер оставлен остановленным. Источники: [жезлы](WANDS_FIRST_SOURCE.md),
[ресурсы](WANDS_FIRST_RESOURCES.md), [таймер](NOMAGIC_SOURCE.md).

Уточнение после первой сборки (user):

> погоди ка, независимое исполнение жезла от стены и сущности это баг, надо исправить. Когда видишь странное поведение - спрашивай меня все таки

Общий луч теперь завершает действие ровно один раз при первом попадании;
Tiny Blind больше не выполняет дополнительный wall-end после entity-end.
[Текущий перенос и проверка](WANDS_SECOND_PORT.md).

## Поведение

- **Tiny Fire** расходует 25 маны и создаёт один нативный SmallFireball:
  от глаз на один блок вперёд, начальная скорость 2,5 по направлению взгляда.
  Полёт, инерция, столкновения, урон и огонь обслуживаются Minecraft 26.3.
  Стрелок назначен владельцем; marker в мировом нуле заменён вычислением
  исходного направленного вектора. Звук прежний: firecharge use, pitch 2.
- **Tiny Blind** расходует 63 маны. Мгновенный луч проверяет 101 точку с шагом
  0,35 (35 блоков между первой и последней), оставляет прежние частицы с
  шансом 30% и останавливается на цели либо блоке вне `minecraft:airs`.
  Endpoint selector использует ячейку 1×1×1 и расстояние до 8; сущность
  получает 0,25 arrow-урона с авторством стрелка, живое существо — Слепоту I
  на 80 тиков. У стены повторяется исходная проверка предыдущей точки.
  Сохраняются звуки squid squirt у цели/стены и вызывающего игрока.
- Каждый жезл оплачивается один раз; предмет остаётся в руке. Настройка
  `offhandWands` соответствует прежней кнопке в слоте 8 и по исходному
  умолчанию выключена (`lefthand=1`). При включении один ПКМ последовательно
  обрабатывает основную и вторую руку, как старый `items/spells`; каждая
  платит отдельно и получает свои cast-бонусы. Дополнительного cooldown нет.
  Creative разрешён, но расход маны
  остаётся. Полный Overload-комплект позволяет действительный долг через
  `LbcMana.trySpendWand`; mage-комплект сам по себе этого права не даёт.
- Полный **mage-комплект** добавляет к максимальной мане 150 после каждого
  успешного каста. Это исходный постоянный бонус до сброса ресурсов матча.
  Цены и бонус читаются из прежних имён score holders в `lbc.math`.
- **Mana Gem** возвращает `60 + 15*(N-1)` маны за N копий. **Blood Anal Boom**
  создаёт один динамит с шансом 25% для одной копии, `20% + 5%*N` для 2–15,
  гарантированно при 16+. Сначала проверяется TNT, затем возвращается мана.
  Счётчик переиспользует нативный helper инвентаря/крафта/курсора; предметы
  не расходуются. TNT использует существующие физику, fuse и трекер
  `LbcItems`, с исходным направлением и малым разбросом. Контекст каста
  передаётся явно: старый Tiny-диспетчер уже стоял у глаз, а `charge_tnt`
  повторно добавлял высоту глаз, поэтому TNT появляется на прежней высоте
  `feet + 2*eyeHeight`. Другие будущие жезлы могут передать свой origin.

Тринкеты доступны в прежнем GUI с исходными условиями открытия: Blood Anal
Boom — ID 5, слот 4, air academy; Mana Gem — ID 21, слот 20, neutral academy.
Дизайн четырёх таблиц взят из исходных payload; все ключи и модели уже есть
в ресурспаке. Пак пользователя, lang и template не редактируются этой пачкой.

## Общие обработчики и ограничения

`LbcWands` содержит оба жезла и cast-хуки. Маска mage-комплекта расширяет
существующий dirty cache `LbcMana`; отдельного опроса инвентаря по тикам нет.
Огненные шары переиспользуют трекер `LbcTrinkets` и эпоху `LbcItems`.
`WandProjectileMixin` отсекает защищённые цели до нативного поджигания.
Blind делает один пространственный запрос на каст, затем проверяет
кандидатов; это сокращение числа запросов, а не измеренный прирост CPU.
Мир, сущности, урон и scoreboard обрабатываются в серверном потоке.

Прямые цели двух жезлов исключают союзников и авторитетных наблюдателей.
Это ещё не полная командная поддержка: вторичные взрывы TNT, окружение,
старые предметы и будущая роль магазина входят в отдельный
[план Teams/BedWars](NEXT_MIGRATION_PLAN.md). Новые режимы пока не включены.

Личный `nomagic` хранит секунды, останавливает только ресурсный цикл:
обычный regen, выдачу/rearm Crux и боевую перегрузку. Он не запрещает каст
при наличии маны либо полного Overload. Аура/маяк и остановка времени
продолжают запрещать жезлы. Обработка зелий и движение Overload-брони
сохраняются; секундный таймер останавливается для time-stop/наблюдателя.
Общая очистка снимает его без возврата ресурсов. Подробности:
[NOMAGIC_PORT.md](NOMAGIC_PORT.md). Мечи, еда и остальные источники этого
таймера ещё не перенесены; здесь готов общий API и проверяемая обработка.
