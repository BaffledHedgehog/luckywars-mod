# Независимая сверка LBCR

Сверил назначенный job `lbc_lbcr` с [исходным документом](lbc_lbcr.md). Inventory и coverage содержат ровно 347 уникальных функций. В [manifest](inventory/lbc_lbcr_review_manifest.json) сохранены SHA-256 каждого файла, точная section coverage, команды, fingerprints и буквальные callers среди функций LBC/LBCR; скрипт воспроизводства — [build_lbc_lbcr_review_manifest.py](tools/build_lbc_lbcr_review_manifest.py). Source-файлы не менялись.

В snapshot совпали по нормализованным командам шесть групп helper-ов (340 разных fingerprints на 347 источников). Существенные совпадения внесены в прозу: `raycast_acid2_inair` = `...inair2`, player-варианты тоже идентичны и оба вызывают `raycast_acid2_player`; `dmg_byentity_1pt` и `dmg_bypl_1nocd` имеют один command body; `raycast_end_with_tp_remove_tag` не очищает tag и является тем же Distance-reset/self-teleport endpoint. Это именно фактическое содержимое, а не вывод по именам.

Сверил также count-условия ключевых веток: электрический upgrade helper требует score count не менее 10 eligible mobs, а молниеносный upgrade helper требует ровно/как минимум четыре transformable item (selector `limit=4`, проверка score `4..`). `if entity` записывает количество совпавших сущностей, не boolean. В существующей документации сохранены узкие селекторы `dx/dy/dz` совместно с distance и различия `as`/`at`; ссылки coverage остаются валидны.

Исправлены найденные смысловые ошибки в `lbc_lbcr.md`: убрано утверждение о различающемся behavior `inair2`, указаны совпадающие функции; для helper-а с именем `remove_tag` исправлено misleading описание очистки; duplicate damage helper обозначен как alias с тем же command body. Для всех 347 LBCR rows проверены точные Markdown headings, допустимые statuses и наличие source-файлов; проблем в них нет. Общий checker после последней правки сообщает четыре section-heading ошибки в другом coverage `lbc_other_events.json` (jack_o_lantern_check/explode/tick и screamer_activate); к LBCR они не относятся.
