## Gameplay scope

Reforge rolls the **original full category catalogs**. These include legacy items whose abilities have not been ported. Importing a loot definition preserves name, lore, models, tooltip, component payload and custom-data flags; it does not implement the behavior represented by those flags. For example, the closure contains 240 library-spell entries with `libspell:1,unresolved_grimoire:1`, six Metasola variants, accessory/staff/summon catalogs and the 18 original armor families. They remain vanilla item definitions plus source custom data unless an existing native service recognizes and converts them. Source entry IDs stay vanilla; no blanket replacement with native wand IDs is made by this importer. Reforge can therefore return legacy items with unported abilities; the resource closure must not be reported as full gameplay coverage for those catalogs.
