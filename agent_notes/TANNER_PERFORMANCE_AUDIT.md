# Tanner performance audit — 2026-10-20

Implementation follow-up: range clipping and Tanner-only early loaded-section
filter are now implemented. Exact pending-position tests and paired native runs
passed; measured results and artifact identity are in [SERVER_TESTS.md](../SERVER_TESTS.md).
The audit below describes the pre-change source. Initial native fill time did
not improve in the measured pair; no total TPS multiplier is claimed.

Read-only audit of current source; no build/server mutation. This is a static audit, not a measured production profile. Root separately found the installed older artifact lacks `BlockAreaWork.class`, so current-source improvements must not be confused with diagnosing that old artifact.

- **First improvement: remove movement's per-pending-cell walk.** `BlockAreaWork.move` (lines 55–68) calls `SectionScan.retain` (170–184) on every surviving section. `retain` visits every queued bit, including cells that remain inside the bounds. A fresh dual cube contains 29,791 cells, and each block-position movement repeats this traversal outside `LbcTanner.drainWork`'s 3 ms deadline. Clip whole Y slabs/Z rows/X ranges using `BitSet.clear(from,to)`; return immediately for sections fully inside the next bounds. This preserves exact pending cells and reduces work rather than raising the allowance.
- **Skip trivially ineligible loaded sections before allocating/enqueuing bits.** Currently `add` queues the full intersection and defers `hasOnlyAir` / `maybeHas` to `step` (lines 120–125). Early rejection saves BitSets and movement clipping for air-only loaded sections. Preserve loaded-only behavior and Tanner's `chunkLoaded` overlap resubmission. `maybeHas` is conservative: native Linear/HashMap palettes retain old state entries, and `GlobalPalette.maybeHas` returns true unconditionally. A fully converted air/dirt section can therefore still pass the palette test after conversion. This causes bounded redundant reads on future new strips/revisits, not perpetual rescheduling. An exact no-eligible cache requires block-event invalidation; do not assume palette membership counts live cells.
- **Writes remain the likely dense-volume cost.** `BlockAreaWork.step` calls native `level.setBlock` once per actual conversion inside `trapChanges`. Each write executes `ArenaBlockMixin`, indirect suffocation/hazard ownership cleanup, map journal bounding-box allocation/union, and aura callbacks. Native `LevelChunk.setBlockState` also updates four heightmaps and performs lighting work when light properties change. Existing Tanner flags already suppress neighbor shape propagation, block-entity removal side effects, and `onPlace`; adding those flags again will not speed it up. Do not bypass native writes or owner/journal hooks without preserving their contracts.
- **Potential mob-dependent native hotspot:** native `ServerLevel.sendBlockUpdated` lines 1136–1165 runs for `UPDATE_CLIENTS`; if old/new collision shapes differ, it loops all `navigatingMobs` and may recompute paths. Many fluid/slab/plant→dirt conversions can cost far more than full-cube→dirt conversions. Profiling should distinguish these. A future scoped bulk-update facility could coalesce navigation invalidations while preserving client block marking, but that needs a separate correctness design.
- **No dirt feedback loop in current source.** `LbcTanner.convertible` (308–311) excludes dirt before event indexing. `SectionScan.positions` is a BitSet, repeated adds merge, `move` clips abandoned sections, and `step` clears a cell before writing it. The section/aura queues rotate fairly. No static liveness failure was found in the ordinary active, loaded, stationary Tanner path.
- **Mana can explain stopping, not slow writes.** `updateHand` charges 500 on activation plus 15 upkeep per hand each tick. Default maximum/current mana is 5,000 with base regeneration 10/tick (`LbcMana`), so continuous dual use spends 30/tick and eventually turns off. Once insufficient, an inactive hand requires 500 again. Accepted pending terrain continues draining after deactivation, although new movement is no longer emitted; particles/active hands and actual mana distinguish this from a stuck queue. Preserve the user-required first paid pulse even when upkeep fails.

Validation priority: benchmark the same dense fixture before/after row clipping and early section rejection, with equal deadlines/allowances; compare both standing conversion throughput and movement queue overhead. Report installed artifact identity separately. No unmeasured speedup claim is justified by this audit alone.
