# Независимая проверка `lbc_other_attributes`

Сверил все 331 исходника из `research_jobs.json` с текущими `.mcfunction`/`.py` и прошёл по прямым caller-ам там, где контекст меняет фактический эффект. Исправления находятся в [lbc_other_attributes.md](lbc_other_attributes.md); этот отчёт фиксирует проверенные семьи и точный read manifest. Coverage использовался только для сверки перечня и точных заголовков, не как доказательство полноты смысла. Поле `content_reviewed` не менял.

## Проверенные механики и найденные края

- 132 attribute/random helpers: base values, scales, постоянные/динамические приращения, integer `trunc` при `base get S` (поправка координатора: дробная часть отбрасывается к нулю, а не вниз), update macros и advancement reset. У God Claw `store result ... if entity` кладёт в `tmp1` число marker-сущностей владельца, а не boolean. Среди 26 функций с суффиксом `_up_godclaw` две реально вычитают `tmp1`: `burning_time_up_godclaw` и `fall_damage_multiplier_up_godclaw`.
- 145 pill handlers: consumable `custom_data:{pill:N}`, точные эффекты/времена/amplifier, attribute calls, specials и сброс advancement. Нестандартные ветки `raid_omen_17/18/19` меняют соответственно `mana +5000`, `manamax +1000`, `manaregen +3`; effect-ветки увеличивают score/tag, а их periodic конечные действия даны отдельной ссылкой на effects contract. `i_found_pills` в checked-in файле не даёт игрового эффекта.
- 41 `drop_inv` helper: каждый копирует stack из собственного NBT/equipment slot в item entity с `PickupDelay:40` тиков; helper сам не очищает исходник. Caller `honew_2` выбирает ближайшего nonspectator игрока, запускает `honey_pl`, который создаёт копии всех занятых 36 inventory slots, offhand и 4 armor slots, а затем очищает эти места.
- 11 new-game/legacy functions: `item_balance:1` запускает reset; schedulers повторяют 1t/1s/5s/5t, обработчики обслуживают non-spectators текущего измерения, каждый5t снимают5 с восьми cooldown scores; старый belt/hat дают дополнительные −2/−4 по семи scores. Периодические циклы не проверяют `legacy`; остановка идёт через `end_resets`. Старые artifact effect/removal helpers были прочитаны отдельно; их конечные действия теперь названы. `swrg:*` и structure resources отмечены внешней границей.
- Два Python scripts описаны как manual generators и оставлены `documented`: `gen.py` при запуске перезаписывает 26 Godclaw функций uniform-шаблоном (и меняет два текущих отрицательных знака), `pillgen.py` перезаписывает 91 pill function генераторными шаблонами без сохранения текущих special cases и без использования собственного счётчика pill ID.
- В coverage `331/331` source paths имеют точные заголовки и читабельные notes; `check_coverage.py` подтвердил `0` link errors. В проектном отчёте проверка показывает `10 800/10 800` связанных источников.

Нерешённых источников или неизвестных границ внутри manifest не осталось. Из внешних границ конечный эффект `swrg:*` не приписываю LBC; scoreboard `effect_*` после постановки счётчика обслуживается описанными в связанном effects документе функциями, не самой pill-функцией.
