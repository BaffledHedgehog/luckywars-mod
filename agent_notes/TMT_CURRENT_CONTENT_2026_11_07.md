# TMT: grouped current-content integration

User requested larger batches. This stage integrates20 Java families with one
manifest and qualifies eight native suites. It is internal, not installed; all
fixes stay on hold until the next stable release. Full TMT remains unfinished.

## Shared owners and actual changes

- The manifest exporter retains literal GLIDER, UNBREAKABLE, DAMAGE_RESISTANT and
  TOOL components in addition to its existing ten private payload types. It also
  normalizes unqualified Minecraft component names and `custom_data`. Semantic
  component values use a bootstrap HashSet instead of copying/scanning every prior
  variant for each source. The source `kit/key_luck.json` Tool speed2 is decoded
  through the native codec and consumed by actual native mining; its old acquisition
  table is not shipped and is not made public by this change.
- Ordinary `most` reuses the lime wool Snowball factory and existing ordinary trail
  owner. Its source semantics remain separate from the different IMBA bridge builder.
- Light blades use their native BLOCKS_ATTACKS component and real faction kill owner.
  Color aliases collapse to one native behavior. Choosing a faction from a TMT item
  spends only its selector property; other properties and the physical item survive.
  Ordinary source selector tokens still undergo their original cleanup and reward.
- Firework use-on and gliding use borrow the existing native factory with authored
  FIREWORKS data. This stage does not claim a complete firework ammunition adapter.
- Rasengan private input calls its existing cast body immediately, without a fake
  snowball callback. Three Apocalypse inputs reuse the actual accepted event owner.
- Chef catalyst/melee/crafting, Infinity intake, Liquid Abyss and yellow lightning
  enter the sampler through their existing native consumers. No parallel effect,
  melee, inventory hazard or encounter engine was added.
- Green Nexus wire now gives its actual `random_glack` reward outside Nexus through
  the same native wire intake, protection and debit code. Four mixed TMT wire colors
  work with the requested cage color. Native proximity crafting excludes its own
  red body and recognizes private green/black siblings on distinct ingredient bodies.
- The QUICK crossbow is explicitly classified as native crossbow plus Quick Charge V,
  which belongs to the existing enchantment generator. It has no additional custom
  use/shot implementation to turn into an independent property.
