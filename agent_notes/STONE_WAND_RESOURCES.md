# Stone wand resource import

- Ordinary item: `loot_table/sauvojen_tuntija_ananta.json` has one carrot-on-a-stick entry named with `sauvojen_wand_stone`, model `lbc:st/stone`, tooltip style `lbc:tier_b`, mana score `ststone_wand_mana_use`, and custom data `{craftusable:1,transformable:1,staff:1,magicwand:1,ststone:1}`. The original lore order, score component, colors, and italic flags are preserved in `ported/stone_wand.json`; only the entry item id changes to `skywars2:stone_wand` after loot schema migration.
- Academy evidence: `advancement/true_advancements/legends/academy/stone.json` uses the same model and recognizes `{upgraded:1,transformable:1,staff:1,ststone:1}`. `item_modifier/swrg_unlocks/ststone_academy.json` is the locked-item display modifier. The existing generic Academy modifiers `item_modifier/add_upgrade_desc.json` and `item_modifier/tiers/a.json` append the green `upgraded_item` line and set tooltip style `lbc:tier_a`. Accordingly, generated `ported/academy_stone_wand.json` carries the ordinary fields plus `upgradable:0,upgrade_available:1,upgraded:1,mode:1`, then those source modifiers. The final tier is A; ordinary tier is B.
- The legacy `plugins/luckywars/values.yml` source configuration sets `ststone_wand_mana_use: 2000`, and `SwrgNativeService.resolveSauvojenWandDefinition` also defines stone as tier B with mana cost 2000 and 4 lore lines. This is the wand's mana activation cost, not a shop purchase price; the loot and Academy source records contain no numeric purchase price.
- The read-only resource pack already contains `assets/lbc/items/st/stone.json` pointing to `lbc:item/st/stone`, and `assets/minecraft/lang/en_us.json`, `ru_ru.json`, and `rpr.json` already contain all five `sauvojen_wand_stone*` keys. No resource-pack additions are needed. English values: `Anantakala`, `Frozen in Amber`, `Creates a large stone`, `Cannot spew more matter until...`, `Can be combined with the Wall Rod or Tannerkivi`. Russian and `rpr` values are retained via the existing keys without duplication.
- Opt-in importer: `python tools/import_lbc_wands.py --stone` writes only the ordinary and Academy stone loot tables.
