## Короткий вывод для переноса

Из этих вариантов **полный ID 5** — единственный подтверждённый кандидат без дополнительных skill/item/projectile веток: при выборе выдаёт Resistance I–IV с вложенными сроками 50/40/30/20 секунд. Все найденные прямые обращения к `lbc.skill=5` ограничиваются selector/page GUI и этим `erose` callback. ID 9 нельзя считать полностью перенесённым одной очисткой эффектов: `gownoman` при potion-effect change — только базовый callback; skill также меняет LBC предметы, броню, лут и item-use эффекты, включая `govno_raskid_mega` с LBC projectile/raycast engine. ID 10 — также не полностью engine-free: кроме 20% шанса teleport/spread до 3 блоков при получении урона, его tick-ветка ищет LBC `raycasters_projectile`.

### Расхождение на второй странице

Обычный `select/10100` реально записывает только IDs 28–36 в slots 0–8. При этом `page/10100.mcfunction` и `select/10100` визуально обрабатывают в дополнительных slots IDs 37–52 и создают для них unlock/card ветки. В селекторе нажатий обычной ветки assignments 37–52 отсутствуют; эти отображаемые карточки не подтверждены как выбираемые обычным GUI. Ranked selector следует оценивать отдельно. Не переносить IDs 37–52 как доступные обычные навыки на основании только page loot. Источники: [`page/10100.mcfunction`](E:/servers_mew/cringe1_21_4_skywars/world/datapacksdisabled/LBC/data/lbc/function/swrg_kit_integration/gui/page/10100.mcfunction), [`select/10100.mcfunction`](E:/servers_mew/cringe1_21_4_skywars/world/datapacksdisabled/LBC/data/lbc/function/swrg_kit_integration/gui/select/10100.mcfunction).

## Первичные side effects и callbacks

`game/skill_select/select` считает pick statistic до начала раунда; снимает старый `manavampire` tag и устанавливает его только для ID 29; вызывает `erose` для ID 5; инициализирует ID 32 через `rainbow_aura/damaged_change_red`. У красной ауры устанавливается +5 attack damage. Это единственные явно обнаруженные одноразовые select side effects в dispatcher; на старте игры `skills/on_game_start` отдельно вызывает Phoenix setup для ID 31 и Absolute Cinema setup для ID 35. Универсальной таблицы «пассивных стартовых attribute bonuses для всех skills» нет. Источники: [`skill_select/select`](E:/servers_mew/cringe1_21_4_skywars/world/datapacksdisabled/LBC/data/lbc/function/swrg_kit_integration/game/skill_select/select.mcfunction), [`skills/on_game_start`](E:/servers_mew/cringe1_21_4_skywars/world/datapacksdisabled/LBC/data/lbc/function/swrg_kit_integration/game/skills/on_game_start.mcfunction), [`erose`](E:/servers_mew/cringe1_21_4_skywars/world/datapacksdisabled/LBC/data/lbc/function/swrg_kit_integration/game/skills/erose.mcfunction).

Основные callback входы datapack: tick, 1-second/5-second interval; damage; inventory change; potion-effect change; bow charge/shoot; hit entity/hit player; kill entity/player; game start. Отдельные item callbacks из `lbc:data/.../items/*` подключают эти входы только при глобальном `#lbcskill >= 1`; индивидуальная функция маршрутизирует по `lbc.skill`. Интервальные dispatchers — [`skills_tick`](E:/servers_mew/cringe1_21_4_skywars/world/datapacksdisabled/LBC/data/lbc/function/swrg_kit_integration/game/skills/skills_tick.mcfunction), [`skills_tick_1s`](E:/servers_mew/cringe1_21_4_skywars/world/datapacksdisabled/LBC/data/lbc/function/swrg_kit_integration/game/skills/skills_tick_1s.mcfunction), [`skills_tick_5s`](E:/servers_mew/cringe1_21_4_skywars/world/datapacksdisabled/LBC/data/lbc/function/swrg_kit_integration/game/skills/skills_tick_5s.mcfunction); event routes — [`damaged`](E:/servers_mew/cringe1_21_4_skywars/world/datapacksdisabled/LBC/data/lbc/function/swrg_kit_integration/game/skills/damaged.mcfunction), [`inventory_changed`](E:/servers_mew/cringe1_21_4_skywars/world/datapacksdisabled/LBC/data/lbc/function/swrg_kit_integration/game/skills/inventory_changed.mcfunction), [`effects_changed`](E:/servers_mew/cringe1_21_4_skywars/world/datapacksdisabled/LBC/data/lbc/function/swrg_kit_integration/game/skills/effects_changed.mcfunction), [`player_hit_entity`](E:/servers_mew/cringe1_21_4_skywars/world/datapacksdisabled/LBC/data/lbc/function/swrg_kit_integration/game/skills/player_hit_entity.mcfunction), [`player_killed_entity`](E:/servers_mew/cringe1_21_4_skywars/world/datapacksdisabled/LBC/data/lbc/function/swrg_kit_integration/game/skills/player_killed_entity.mcfunction).

### Полное поведение ID 5 и ID 9

Проверка `rg --no-ignore` всех LBC datapack-функций по `lbc.skill` подтверждает, что ID 5 ссылается только на выбор/GUI и `skill_select/select → skills/erose`; самостоятельной ID 5 item synergy или projectile ветки не найдено. Это делает ID 5 полным кандидатом для первого переноса при условии, что точная выдача длительностей/amplifier-ов сохранена.

Для ID 9 `effects_changed → gownoman` снимает только nausea, poison и wither, но другие прямые ссылки включают:

- [`workingitems/govno.mcfunction`](E:/servers_mew/cringe1_21_4_skywars/world/datapacksdisabled/LBC/data/lbc/function/workingitems/govno.mcfunction) выбирает `govno_govnomen`; [`workingitems/shit_katana.mcfunction`](E:/servers_mew/cringe1_21_4_skywars/world/datapacksdisabled/LBC/data/lbc/function/workingitems/shit_katana.mcfunction) подключает `shit_katana_gownomen`.
- [`armor/gownoleggings/select.mcfunction`](E:/servers_mew/cringe1_21_4_skywars/world/datapacksdisabled/LBC/data/lbc/function/armor/gownoleggings/select.mcfunction) удваивает `shit_amount_temp` до dispatch соответствующей armor ветки.

## Границы режимов

**Да, LBC kits и skills могут действовать в обычном SkyWars**, если соответствующие глобальные переключатели включены. Обычный вход SWRG `game/start/1` вызывает LBC kit selector для всех игроков при `#lbckit swrg.math=1`, а skill selector — независимо при `#lbcskill swrg.math=1`; это отдельные guards от ванильного `#kit`. Затем runtime player/item callbacks продолжаются в матчевом тике. Значит интеграция не ограничена отдельным LBC mode. При `#lbcskill=0` выбранный `lbc.skill` сам по себе не означает runtime выполнения; при `legacy=1` большинство callbacks блокируется. Ranked — это режим bypass для GUI-unlock, а не требование для использования LBC в обычном SWRG матче. Источники: [`SWRG game/start/1`](E:/servers_mew/cringe1_21_4_skywars/world/datapacksdisabled/swarogskywars/data/swrg/function/game/start/1.mcfunction), [межпакетный аудит](INTEGRATION_REVIEW.md), [GUI и unlocks](lbc_kit_interface.md).

`lbc.kit` и `lbc.skill` — независимые выбранные scores. Настройка разрешения выдачи LBC kit не включает автоматически skills, и наоборот. GUI вход из главного меню SWRG доступен без отдельной проверки permission; именно selector карточек проверяет advancements. Обычная закрытая карточка не меняет выбранный score, а выводит lore; ranked page/select обходит это условие.
