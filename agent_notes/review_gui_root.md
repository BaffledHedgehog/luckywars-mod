# Приёмка GUI координатором

Принят участок `skywars_gui` (397 источников) после полного прохода исследователя,
чтения итоговых человеческих описаний и отдельной сверки наиболее рискованных
контрактов координатором. Это анализ файлов отключённого datapack; работа меню
на запущенном сервере не проверялась.

Исправлены ошибки итогового текста:

- Обычный инвентарь очищает `gui/main` каждый лобби-тик. `gui/page` очищает
  EnderItems при обновлении/выборе; ванильного `clear` в нём нет.
- Страница 4000 выбирает навыки SWRG. Суффикс 19 находится в слоте 19;
  слоты 19–24 соответствуют суффиксам 19–24, а 25 находится на странице 7310.
- `7400_halloween` и `7500_halloween` пустые. Только `7300_halloween`
  действительно меняет закрытые кнопки суффиксов на сезонную модель.
- Компас исключает расстояния менее 0,1 блока. Модификаторы топоров
  заменяют весь список attribute modifiers, а не добавляют атаку к старому списку.
- В награде есть `rewardbar:21`, но его нет во всех 254 назначенных loot tables
  и в выборе bars. Удалён повтор абзаца о ролле.

В [gui_root_audit.json](inventory/gui_root_audit.json) сохранены полные JSON-контракты
и исходные команды пяти вариантов ролла. Утилита проверяет полное равенство
29 предикатов, 42 команд scheduler, 47 команд выделения case ID и 47 команд
покупки ключей, включая порядок начисления и списания. Проверены все JSON
задания, отсутствие `rewardbar:21` и обе пустые сезонные функции.

Ручная сверка подтверждает: case ID выбирается последним свободным из 1–8;
ключ расходуется на первом шаге; scheduler выбирает случайного подходящего игрока
для каждой пары page/ID и уменьшает таймер после вызовов. Роллы сдвигают 27
контейнерных слотов, выдача читает слот 2; have-ветки удаляют `id` уже открытых
наград и вставляют компенсацию. Reset освобождает ID и возвращает страницу.
Функции 0–4 различаются fill/reward/have и моментом повторной have-проверки;
они не описаны как пять полностью одинаковых алгоритмов.

Веса case1/case2/sounds дают 550/350/90/10 из 1000; bars — 550/90/10 из 650,
case4 — 55/35/10/1 из 101. Все значения в человеческом описании сверены с
JSON; веса вложенных веток не приравниваются к вероятностям каждого предмета.

Отсутствующий `swrg:gui/fill`, maploader 65–76 и внешний экран контейнера
сохранены как границы снимка. Их наличие на работающем сервере не предполагается.
Соседние LBC-страницы рассмотрены в уже принятом kit_interface.
