# Наблюдатели в Fabric

Требование пользователя: умерший игрок может менять личный билд, не участвуя в матче; ПКМ по сущности включает её камеру. Реализация сосредоточена в [Spectators.java](../src/main/java/me/skywars2/game/Spectators.java).

- Отдельный реестр UUID определяет роль. `game.isObserver(player)` — обязательная проверка для новых предметов, целей и игровых событий. Gamemode не определяет участие в матче. `alivePlayers()` и `allowDamage()` исключают наблюдателей.
- Вне камеры клиент получает Adventure, полёт и невидимость. Серверная проверка `isSpectator()` возвращает true для зарегистрированного наблюдателя, чтобы нативные AI и физика также исключали его. Селектор `@a` продолжает включать таких игроков: командные механики должны фильтровать их отдельно.
- Компас в центральном слоте открывает личные разделы SkyWars. Настройки, старт, карты и BedWars закрыты. Выбор перков сохраняется для следующих выдач; наблюдатель не получает способности своего нового билда в текущем матче.
- Голова в слоте 6 открывает список живых участников; нажатие телепортирует к выбранному игроку. ПКМ по подходящей сущности включает настоящий Spectator и её камеру. Выход из камеры через Shift либо `/sw detach` возвращает инструменты.
- Для камеры игрока копируются его стаки, выбранный слот, здоровье, поглощение, голод, XP, огонь, замерзание, воздух и эффекты. Стаки независимы от оригинала; их использование, перемещение, выбрасывание и подбор запрещены. Нативные `inventoryTick` скопированных предметов отключены.
- Эффекты передаются пакетами для отображения. Серверные эффекты на наблюдателя не накладываются: скопированные Raid Omen и другие callbacks не должны запускать игровые механики. Снимки подавляют повторную отправку неизменившихся эффектов при обычном отсчёте длительности.
- `/sw inventory` открывает копию инвентаря цели в отдельном меню для просмотра. Обновляются изменившиеся стаки. Камера не гарантирует, что клиент разрешит открыть обычное E, поэтому предусмотрена эта команда.
- При исчезновении/смерти цели камера снимается. Возврат в лобби, отключение и остановка очищают роль и временные копии. Наблюдатели не получают достижения за скопированные предметы и положение камеры.

Каждый тик обходятся только зарегистрированные наблюдатели. Для камеры игрока сравниваются слоты инвентаря; серверные записи и синхронизация выполняются при изменениях. Это описание алгоритма, а не результат нагрузочного измерения.

Сценарии `/sw check regressions` и `/sw check observer-match` проверяют нативные пакеты открытия меню/камеры, копии инвентаря, cache эффектов, запрет взаимодействий и подбор предметов. Итог фактического прогона фиксируется в [SERVER_TESTS.md](../SERVER_TESTS.md). Отображение камеры, HUD и скрытие наблюдателя от настоящего клиента требуют визуальной проверки.
