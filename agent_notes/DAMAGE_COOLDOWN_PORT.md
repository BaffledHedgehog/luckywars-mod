# Частота попаданий и legacy bypass cooldown

Уточнение user, 20 октября 2026: перенести весь прежний список без
ограничения только отдельными предметами. Быстрые обычные стрелы и заряды
Stblind должны регистрировать каждое попадание, включая одну цель за тик.

Источник — `E:/servers_mew/cringe1_21_4_skywars/world/datapacksdisabled/LBC/data/minecraft/tags/damage_type/bypasses_cooldown.json`.
Других файлов с таким именем в старых отключённых датапаках не найдено.
В активном моде раньше присутствовали только узкие skywars2-типы, поэтому
ванильные arrow/generic ошибочно оставались с обычными invulnerability frames.

Восстановлены все 14 записей:

| Тип Minecraft | На что распространяется |
| --- | --- |
| arrow | Обычные стрелы, включая быстрые повторные попадания из лука |
| falling_anvil, falling_block, falling_stalactite | Соответствующий урон падающих блоков |
| fireworks | Урон фейерверка |
| mob_projectile | Соответствующие снаряды мобов |
| sting | Укусы/жало этого типа |
| thorns | Урон шипов |
| thrown | Брошенные снаряды этого типа |
| trident | Трезубцы |
| wither_skull | Череп визера |
| outside_border | Урон данного типа за границей |
| generic, generic_kill | Соответствующие общие источники; Stblind использует generic |

Файл мода сохраняет `replace=false`: исходное содержимое Minecraft и
11 собственных skywars2-типов не теряются. Меняется только допуск повторного
попадания через штатный damage tag. Броня, величина урона, фильтры команды,
авторство, cooldown использования предмета и число снарядов не переписываются.
HurtTime и таймеры не сбрасываются вручную. Это глобальная политика типов,
а не отдельная проверка того, какой предмет сейчас держит атакующий.

Vanilla `lightning_bolt` и управляемый `skywars2:lightning` не включены.
Последнее уточнение о ванильной частоте молний сохраняется. Direct Electro,
проводимость и специальные лучи по-прежнему используют свои уже подключённые
типы с bypass cooldown.

Build и 9 серверных suites прошли на SHA `f715e0c5…`: все 14 типов проверены
реальными повторными `hurtServer`, отдельно проверены BowItem-стрелы и
два Stblind-заряда в одном тике, сохранение cooldown молний и обычного melee.
Проверенная сборка готова без установки. [Результаты проверок](../SERVER_TESTS.md).
