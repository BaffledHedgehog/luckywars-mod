# Acid Academy native checks

`AcidAcademyChecks.run/tick` supplies the asynchronous `acid-academy` suite.
Academy assignment and promotion occur on separate actual server ticks, keeping
the production duplicate-click guard intact. The suite uses real singleton
ordinary/Academy loot and native `ServerPlayer.gameMode.useItem`; legacy vanilla
carriers additionally exercise the shared wand callback.

Coverage:

- Distinct native ordinary and Academy identities, source custom flags, default
  mode1, model, B/A tier, seven authored lore rows and Academy upgrade marker.
- Free zero-mana Shift selection/wrap in both hands, legacy/native carriers,
  independent dual-hand selectors, offhand configuration and no mode-change shot.
- Both paid modes in each native/legacy used hand:249 rejects,250 debits once and
  produces exactly one existing native big ordinary-acid projectile. Academy
  shots have exact eye origin, owner and aim, source speed0.2, shared native
  gravity, existing300 lifetime and source ignition only for mode2. Actual dual
  native input spends500 and retains independent ignition selection.
- Ordinary shots still use source yaw +/-30 and pitch +/-20 random spread.
  An actual native projectile tick exercises movement/gravity. Existing ordinary
  actor passage and Greed collision are retained. Shared poison impact protects
  teammate players and technical roles while hitting friendly mobs with600tick
  poison. Existing acid age freezes during dimension Time Stop.
- The personal `nomagic` regeneration countdown preserves source paid casts
  (one250 debit and one shot). Actual antimagic fields and individual/dimension
  Time Stop block cast admission.
- Real Academy trial assignment. Nonburning casts keep the trial pending; burning
  unpaid casts cannot complete it. Paid burning casts in either native/legacy
  hand immediately ready only the actual used ordinary stack, retain the ordinary
  shot and debit250 exactly once. Two ordinary trials, mixed Academy/ordinary
  hands, and unrelated fire trials cannot borrow readiness from another hand.
- A real grounded token builds the native school. The real promotion callback
  yields native Academy acid with mode1/A tier and matching source presentation,
  then consumes the single-use school.

The fixture requires exclusive empty acid/Academy services and resident columns.
It restores complete player inventories/craft/cursor, effects, attributes, movement,
fire, abilities, scores, profile/config fields, teams, stats, advancement criteria,
Academy click timestamps, exact school-area block/BE snapshots and scheduled
block/fluid ticks. Fixture poison attribution is cleared before player restore.

`stopProbe` creates a real native mode2 shot, retains it away from participants,
and immediately restores the player's complete state. Invoke it immediately
before the other retained pause probes and actual match stop; individual
`time_stopped` tags alone do not freeze the shared acid age counter. `cleanup`
asserts the real epoch changed, the cloud service is empty and that exact native
projectile was discarded. The retained probe does not extend acid lifetime.
