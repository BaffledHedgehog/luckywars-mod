# Mystical artifact liquid resource import

`src/main/resources/data/lbc/loot_table/ported/mystical_artifact_liquids.json` imports the `artifact.json` entry selected by `unresolved_artifact:1`, `mystical:1`, and `type:3`. It changes only the server item id to `skywars2:mystical_artifact`; the migrated source name, lore, formatting, model, tooltip style, and custom data are retained.

The selection is generated by `tools/import_lbc_weapons.py` and independently compared to the read-only old datapack by `tools/check_design_sources.py`. The resource is included in the Gradle resource allowlist. No resource-pack translation or template was added; this item reuses the existing `mystical_artifact` and `mystical_artifact.lore` keys and source model.

The source effect audit and candidate implementation boundary are in [ARTIFACT_LIQUIDS_NEXT.md](ARTIFACT_LIQUIDS_NEXT.md). This file records only the loot resource transfer; effect behavior is not implemented here.
