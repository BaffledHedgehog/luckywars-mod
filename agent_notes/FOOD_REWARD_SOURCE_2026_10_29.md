# Reward food source and native consumers - 29 October 2026

Read-only source audit; implementation is in progress in parallel. No build, server run, production/resource/RP edit or commit was performed for this note. The complete original Chaos pool remains gated; this note does not change `root_PENDING` or qualify a release. Protected author files and live overrides are outside this edit.

Legacy root: `E:/servers_mew/cringe1_21_4_skywars/world/datapacksdisabled/LBC/data`. Both `lbc` and `lbcr` were inspected. There are **87 top-level consume criteria in lbc, zero in lbcr**. Every top-level criterion is named `requirement`; there are no root-parent requirements that make these definitions dormant. Flags are independent: a stack carrying several matching raw flags can trigger several criteria. `eat_lava` and `eat_snow` are **using_item**, not consume_item, despite their filenames.

## Source admission and exceptions

86 of the 87 consume roots exclude both `minecraft:nexus` and `minecraft:imprinted`, using two inverted entity-properties conditions. They do not test participant roles, game mode, Time Stop, MAG, TECH, mana, or a jammer marker. The sole exception is `eat_halloween_food`, which has **no player/dimension condition**. Current shared gameplay/role/Time Stop policy is an integration requirement, not an extra condition found in those source criteria. Source function effects still enter the shared effect/damage engine; do not bypass existing native immunity/effect policy.

The transitive explicit function graph has **138 functions**, including scheduled helpers; all files exist. Explicit calls and schedules were followed after removing commented command lines. The index below is the reproducible static boundary; tags, ambient entity schedulers, loot-produced active items and cross-dimension infrastructure add further runtime edges and are not implicitly qualified by that count.

* `eat_damage_all` calls `workingitems/omegaflag`, not an ordinary self-buff. Its entity selectors exclude `spectator` tags and `lbc:nexus` at each target; each target also requires **no marker `stopper_magic` within 20**. The predicate checks nexus only, not imprinted. Players receive cactus6 with caster attribution; nonplayers source cactus6 had no author (the port must retain the project attribution requirement). Its optional selected-item `upgradable` path can enter Academy helpers.
* `human_flesh` selects a random `@a[gamemode=!spectator,tag=!owner,limit=1]`, including allies, then exchanges positions through a temporary marker. No source enemy/team filter or distance limit. `human_eye` adds `all_seeing_eye=12000` after its three short debuffs.
* `oreshek` first calls `random_debuff`; chance10 (0.1) returns a fuse0 TNT/explosion_power15 branch; otherwise plays Ukraine8/1, then chance1 (0.01) returns a genuine Nexus teleport; otherwise chance001 (0.0001) returns the Zelensky marker/piglin/four-drone branch. These are sequential conditional draws, not three exclusive normalized weights. Early returns skip the root advancement revoke. `leave_death:1-3` explicitly reads that completion to broadcast U+E202 and then revokes it. Preserve that persistent death marker or obtain an author decision; do not accidentally erase it through a stateless callback.
* `halloween_chorus` summons **20** damaging falling pumpkins at Y+.5, each with X/Z random -50..50 and Y50..150, scaled .01; emits authored particles/sound and calls native spreadplayers radius10. This is a real missing consume bridge/new native consequence, distinct from the already existing Halloween wind service.
* `eat_halloween_food` adds one `pumpkin_counter` and grants the matching **individual criterion 1..100** of its real event advancement. The helper does not revoke itself; `players_tick:70` revokes its root each tick. This is repeatable source behavior, not a one-time counter. Its absence of dimension restriction differs from the other roots and from the current global custom-item sealed-dimension gate.
* `inf` replaces **mainhand** with one original cooked-beef infinite steak immediately. `inf_old` tags the consumer and schedules a one-tick helper replacing **mainhand** with original rabbit stew, then clears scheduled tags. This exact source hand choice also applies when the triggering item was consumed from offhand. Component `use_remainder` cannot reproduce those hand/scheduling semantics alone.

## Components versus scripts

`food`, `food_old`, `foodblocks` and `imba/foodblocks` are ordinary native item output; no custom food-effect engine is justified for them. `stews`/`stews_old` and the suspicious-stew rows embedded in Infinity use native `suspicious_stew_effects`; keep those components and native consumption. The effect ID/duration codec still exists in26.3. Vanilla food defaults already own food nutrition, sound, native remainder and default golden-apple effects.

Conversely, `attributefood`, named imba foods, rofls, infinite food, bananas, nuts and Halloween flagged entries need their actual reward script/bridge **in addition** to vanilla component behavior. A golden_apple carrier has its vanilla apple effects before/alongside the source extra effects; it is not permission to replace the source function with those defaults. Raw vanilla item carriers must retain custom_data/presentation; no custom registry item is necessary merely to recognize a source flag.

`gluttony` matches the exact **41 IDs in #minecraft:all_food**, not the presence of FOOD or CONSUMABLE components. It includes milk_bucket/honey_bottle; excludes banana stick and edible slab/ordinary bucket carriers. Preserve native registered KFC/cookie aliases as their original cooked_chicken/cookie carriers when implementing this classification. The tag exists in the source/current tree but must be explicitly packaged if used (current build's swrg:food inclusion is a different skill tag). One consumption may legitimately trigger both a specialized flag and food_count; CannedFood's passive clear does not trigger native consume_item.
