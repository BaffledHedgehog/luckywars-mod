## Sibling classifier isolation

The earlier scope isolated mode/version/type, but retained all other aggregate
ability flags. A native handler inspecting multiple flags could therefore execute
a neighboring property's branch again. `LbcTmtAbilities.invoke` now removes the
union of property-owned keys before projecting the chosen payload. General item
metadata and identity remain available; after the callback, the full outer aggregate
is restored, and native property writes remain private as before.

The change is inside the existing bounded seven-slot activation scope, not a second
dispatch or damage engine. Inventory masks are read during actual jump/source-armor
callbacks. No tick task, global scan, registry enumeration or file parsing was added.
NBT work is bounded by the source slot count; this is not a peakTPS measurement.
