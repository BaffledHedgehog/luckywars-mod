# Exoperso wand resources

The ordinary entry is selected from `data/lbc/loot_table/transformables_staff.json` by its `minecraft:item_model` value `lbc:exoperso`. Its source name key is `megumin_wand`; its custom data is `{craftusable:1,transformable:1,staff:1,magicwand:1,exoperso:1}`. The source lore, styles, blue name color, `lbc:tier_a` tooltip style, and `lbc:exoperso` model are carried into the native `skywars2:exoperso_wand` loot table.

The actual `other/magic_academy/upgrade/exoperso.mcfunction` says `upgrade_succesful_exoperso` and applies `lbc:tiers/s`, so the Academy item uses the source `tiers/s` modifier and Tier S. That function contains no explicit custom data flag changes or item/material payment. The Academy table follows the existing imported-wand Academy metadata convention (`upgradable:0,upgrade_available:1,upgraded:1,mode:1`); those flags are importer metadata, not commands found in the source upgrade function.

The source upgrade eligibility/cost path is `workingitems/exoperso_check_upgrade.mcfunction`: it reads the item's `score`, adds 1, writes it back, and calls `other/magic_academy/can_upgrade` when the result reaches 5. Thus the source criterion is five accumulated score points; the source files do not specify a separate Academy payment. The `5000` configured for `megumin_staff_mana_use` in `function/config.mcfunction` is activation mana, not upgrade cost.

Files generated by `tools/import_lbc_exoperso.py`:

- `src/main/resources/data/lbc/loot_table/ported/exoperso_wand.json` → `skywars2:exoperso_wand`
- `src/main/resources/data/lbc/loot_table/ported/academy_exoperso_wand.json` → `skywars2:academy_exoperso_wand`

The driver reuses `import_lbc_wands.import_wand_family` and `migrate_loot_schema`.
The shared selector accepts distinct name/data markers: `megumin_wand` and `exoperso`.
No temporary source edits or artificial translation keys are required.

Mana (user, 17 October): admission requires 5000, but a successful cast debits
25000 ordinary / 10000 Academy. The original 5000 in lore is preserved deliberately.
Full Overload bypasses admission; the real debit still applies.
