# Explicit mob owner clone images ? implementation, 2 November 2026

This note records unqualified implementation work. No build, native process,
installation, resource change or gameplay exposure was performed by this owner task.

`CloneMobStates.capture(game, entity)` must run on every admitted body, including
vanilla bodies: Communism ownership and Soulless ghost/incarnation overlays do not
have unique managed tags. `recognizes` identifies managed families; a null image
means no scoped state was found, and must not permit a known managed shell fallback.
`protectedActor` excludes consuming trial actors, Soulless trial Vex/display children,
and Lust dragons that own active player transformation/control. Standalone Lust
produced mobs retain their source author/cause and acquire their own clone emitter.

Owner images install private indexes before native ENTITY_LOAD adoption, without
casting, spending mana, resetting source timers or changing the source body.
Summons reconstruct all ten custom native subclasses, copy immutable ownership
records, attach one fresh order goal, preserve assigned targets through the family
map, and independently reproduce waiting/running StrangeRay records with original
cadence, due time, origin, direction and step. Rollback removes clone records only.
Communism copies its UUID controller entry without rerunning subjugation.

Soulless reproduces ordinary GhostVex caster/retired state and custom loot class,
ghost owner/cause/frame/effect_ghosting seconds, and incarnation cooldown. Metasola
Body retains its field type, owner, cause, age and frame, with exactly one new Visual
whose durable native display NBT is copied at capture and whose identity is fresh.
The field index exists before visual publication. Rollback removes the clone field
and its visual. Displays remain independently protected. Native main-body state,
attributes, effects and runtime belong to the shared native image.

Kfc reproduces CultBat, CultItem and LooseBolt factories and ownership, hostile
lightning causes and bomb variant/epoch/controller. CultBat is a gameplay carrier,
not a protected visual: the shared native passenger-tree clone owns bat/item links.
Items are not independently admitted by this owner task. Free standing bomb items
can be reconstructed when the shared owner calls their image explicitly.

Indolence fingers retain source authority and independent pending finger-payment
records with the original player, born tick and remaining countdown, rekeyed to the
clone finger. Player rebirth queues and control authority are not copied. Family
actors have no private parent/child links: their native equipment/tags and native
clock tags carry behavior, and the clone is added to the derived actor index.
Consuming has only protected trial native summons, so no empty protocol was added.

This is one adapter component, not a complete coverage claim. Shared source/effect,
indirect consequence, native relationship, lifetime and remaining controller owners
are integrated and qualified by the root task. Original causal ownership remains
external unless the family link explicitly points to a copied actor. No arbitrary
vanilla brain-memory cloning or generic reflection is introduced.
