# LBC loadout: source audit for transfer stage 1

Сверка: старый datapack `E:/servers_mew/cringe1_21_4_skywars/world/datapacksdisabled/LBC`; authoritative user notes in `agent_notes/AGENTS.md` take precedence. В `lbc_kit_game.md` нет пометок `(user)`.

- Начало матча: `data/lbc/function/bedwars/game/start.mcfunction` последовательно вызывает `game/trinket_select/select` (если `#lbctrinket>=1`), `game/kit_select/select` (`#lbckit=1`), `game/levelup_select/select` (`#lbclevelup=1`), skill selector, затем challenge content selector; после этого ставит `game_started=1`. Входы и порядок важны для повторного учёта pick stats.
- Respawn: `data/lbc/function/respawn.mcfunction` вызывает kit, skill и challenge kit selectors (пороговые score `>=1`), но не trinket/levelup. Альтернативный `data/lbc/function/bedwars/player/respawn.mcfunction` очищает игрока, даёт 30 уровней и вызывает kit, skill, trinket (каждый при соответствующем `#lbc*=1..`); levelup отсутствует. Challenge kit выдаётся отдельно через `lbc.challenge` в первом respawn.
- Kit IDs и loot keys, 1–25: `broken_totem`, `3_purify_potion`, `gaara`, `life_in_death`, `hell`, `lucky_baffled`, `moisei`, `multiply_tablet`, `nanobot`, `ghost`, `govno_raskid`, `steampunk`, `hook`, `key`, `dynamite`, `key_luck`, `brbad`, `phd`, `blazefire`, `clown`, `deus`, `explosive_feets`, `fast_sword`, `palm_with_bananas`, `reroll_machine`. Источник mapping: `data/lbc/function/swrg_kit_integration/game/kit_select/select.mcfunction`; JSON: `data/lbc/loot_table/kit/<key>.json`. Challenge `lbc.challenge.kit=1` выдаёт `kit/academy_token`.
- На уровне исходного payload IDs **4, 5, 7, 10, 23** не содержат entity_data, вложенных loot или LBC sentinel potion effects: #4 выдаёт 3 healing + 1 Instant Damage III + 2 strong-harming splash; #5 obsidian×16, flint-and-steel, Fire Resistance 1200t; #7 dirt×16×64; #10 четыре splash invisibility II + strength II на 100t; #23 golden sword с vanilla attributes damage +6, attack speed −2.4, movement speed +50%. #10 дополнительно запускает LBC advancement `true_advancements/potions/effect_high_invisibility.json` при invisibility amplifier≥1: для полного совпадения перенести/проверить этот event/toast. Это перечень payload-кандидатов, не утверждение о готовности всей runtime-интеграции.
- Исключить #9 и #17 из «ванильных»: panda egg #9 задаёт `entity_data` marker с tags `slowraycast`, `nano_trapik`, `player` (это LBC nano projectile, не panda); у #17 четыре lingering potion несут скрытые `raid_omen` amp 234–237 на 20t, используемые как sentinel LBC potion-engine.
- ID2 не самодостаточен: pool 1 с тремя выдачами вызывает вложенную таблицу `lbc:purifypotion_1` (не `purifypotion_1` без namespace); она задаёт `custom_data={transformable:1,potion:1}` и `raid_omen` amp43/duration100, требуя potion-event/transform handlers. Две другие pools дают milk_bucket×3 (обычные, только max stack 3) и 4 splash instant_health amp5. Полный стартовый каталог требует 25 kit JSON и их nested tables; ID6 выдаёт 16 `luckyblock_block_only` + по 1 `luckyblock_neko_block` и `luckyblock_loli_block`. Не приравнивать выдачу vanilla base item к рабочей LBC ability.
- Trinkets: `trinket_select/select.mcfunction` распаковывает до 12 packed IDs из `lbc.trinket1..3`; `select_1.mcfunction` maps IDs 1–18, 20–24 (ID19 отсутствует) в `loot_table/trinket/{blaze,ghast,penis_gun,drojjevoe_odealo,blood_anal_boom,mandoahuet,bedrcock,nether_plug,volos,intercal,cocktail,banangay,fourier,rocket_spell,twilight_sparkle,gneiss_stone,hedgehog_gauntlet,snow_gem,ice_gem,mana_gem,poly_gem,glass_shard,psycho_soul}. Все эти выдачи несут trinket custom data; полная выдача требует перенести весь каталог и сохранение `custom_data.trinket`.
- Каждый вызов trinket selector затем перемещает предметы с этим component из hotbar 0..8 в inventory с целевого slot 4 вверх, без проверки занятости; повторная выдача заменяет содержимое destination slots. Challenge trinket selector пуст.
- Levelup: `levelup_select/select.mcfunction` сначала выполняет `levelups_remove`, затем читает три scores `lbc.levelup1..3`, распаковывая по 4 двухзначных ID на score; active-position лимит `#lbclevelupmax` — 1..12. `select_1.mcfunction` применяет ветки ID 1..44 (19, 26, 27 пусты); ID14 выбирает random perk 1..44, ID1 выбирает равновероятно один из 21 stat bonus. Повторный расчёт очищает старые modifiers/tags перед применением; не реализованные ветки нельзя заменять нулевым эффектом незаметно.
- Для полного базового контура нужны эти dispatcher/helper файлы, полный набор kit/trinket loot JSON + nested loot, levelup modifier remove/apply branches и необходимые attribute/mana scoreboard состояния. Pick-stat path также читает player name через `kit_select/select`-подобный helper `loot_table/player_name_head`/stats storage. `levelups_remove_1.mcfunction` раскрывает внешнюю команду `regen set 0 @s`; её реализации в datapack нет, поэтому переносу нужен совместимый command bridge либо отдельная реализация. Источники selectors: `data/lbc/function/swrg_kit_integration/game/{kit_select,trinket_select,levelup_select}/`; стартап/respawn call sites перечислены выше.
