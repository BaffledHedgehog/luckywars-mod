# Независимая семантическая проверка `lbc_other_imba`

Все293 уникальных источника из job сверены с полными body и местом вызова. [Read manifest](inventory/review_other_imba_read.json) фиксирует exact path, SHA-256, число команд, способ проверки и точный заголовок coverage; [source manifest](inventory/review_other_imba_manifest.json) сохраняет полный текст всех команд и literal callers. Итоговый read-method счётчик:178 `manual`,115 `full-command template`.

Повторяющиеся варианты не сокращались по первым outputs. Полная таблица описывает каждый из100 `cunny_slab/pasta/<n>` наборов по четырём строкам (400 точных строк), каждый из16 цветовых effects,22 Cunny slab outcomes, шесть cultist branches,32 Blood Slab outcomes и10 mob outcomes, пять window-вариантов God Hedgehog arrows, все rune casts и крупные root-level механики. Особые шаблонные проверки: `chaos_sho_use` содержит420 ray calls,28 разных локальных смещений и ровно15 повторов каждой; Imbaxe имеет216 строгих fill-команд —215 конкретных block IDs и `#minecraft:leaves`, который идёт в счётчик `stick`; макрос содержит217 give-команд и216 уникальных item IDs (`bamboo_mosaic` повторён, три mushroom outputs имеют собственное оформление); `tmp` обнуляет212 `IF` counters; IDs11..20 Cunny Slab — одинаковые TODO/no-effect bodies с соответствующим сообщением и расходом.

Исправленные смысловые ошибки включают: Blood Slab raycast 1000 шагов×0,025 блока означает максимум25 блоков; число сущностей в terminal `execute store result ... if entity` — count; God Hedgehog ray делает101 TNT на расстоянии до300 блоков, а не несколько общих взрывов; `delta_ex_tick` содержит20 независимых 1%-проверок; обычный съеденный Bad Apple и dropped `bad_apple_imba` — два разных входа; Cunny Slab 4 повторяет четыре позиции радиуса2, а номер21 выбирает до64 сущностей без фильтра; Thurisaz/Raidо/Nautiz/Wunjo имеют глобальные состояния и reset-границы, описанные по командам; Chaos Hoe ограничен 100 шагами по0,1 и может снова встретить ещё свежий item после сброса Distance; Chaos Shovel запускает420 ray-команд, из которых только28 origins уникальны, а hit-helper зависит от неинициализированного в cast-е fake-player `if`.

Проверены внешние entrypoints, нужные для условий: advancement-ы Imbaxe/Bad Apple/Blood Slab/Chaos tools, Cunny item selector, legacy artifact ticks, effect wrappers, projectiles и runtime raycast dispatch. Внешние функции, на которые эти участки передают управление, в отчёте связаны с их exact source; их собственные чужие coverage/status файлы не менялись. `content_reviewed` и registry статусов не редактировались.
