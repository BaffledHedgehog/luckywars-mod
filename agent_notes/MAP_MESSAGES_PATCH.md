# Переводы выбора карты и недоступного режима

В read-only паке пользователя `C:/Users/yarik_temp/AppData/Roaming/FreesmLauncher/instances/26.3(1)/minecraft/resourcepacks/all_in_one_1.21.8` уже есть ключ `skywars2.game.map_selected` в обоих файлах `assets/minecraft/lang/ru_ru.json` и `en_us.json`.

Исходные значения утверждали, что выбранная карта загрузится при старте матча. Карты подготавливаются сразу, поэтому patch заменяет только значение существующего ключа:

- RU: `Выбрана карта %s (%s).`
- EN: `Selected map %s (%s).`

Примени одно-ключевые patch-файлы `resourcepack_template/updates/map_messages.ru_ru.json` и `map_messages.en_us.json`, заменив значение существующего ключа в пользовательском паке. Не добавляй дубликат и не заменяй полный языковой файл.

Ключ `skywars2.game.mode_unavailable` отсутствовал в обоих языках живого пака. Переводы RU/EN добавлены в языки мода и существующие языковые файлы `resourcepack_template/assets/minecraft/lang/`. Если ключ всё ещё отсутствует в пользовательском паке, объедини с ним эту одну новую запись. Файлы template не являются полной заменой языковых файлов.

Живой ресурс-пак не изменялся. Этот patch подготавливает текст для переводимых компонентов; его наличие не подтверждает проверку отображения на клиенте.
