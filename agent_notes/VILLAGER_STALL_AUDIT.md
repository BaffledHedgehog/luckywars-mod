## Сбор следующего эпизода

Без остановки основного сервера включены:

- JFR `skywars-stalls`, настройки JDK `default`, disk=true,
  maxage=30m, maxsize=128m, dumponexit=true, вывод в `diagnostics/`;
- `diagnostics/gc-safepoint.log`: GC и safepoint с временем/uptime,
  ротация `filecount=5`, `filesize=4M`.

Те же параметры добавлены в серверный `start.bat`; его прежний вариант
сохранён как `diagnostics/start-before-stall-diagnostics.bat`.
Игра, конфигурация матчей и JAR не изменялись. JFR продолжает работать;
при следующем фризе важно сохранить снимок, пока эпизод ещё в кольцевом окне.
Профиль default выбран для непрерывного сбора; нулевые накладные расходы
не обещаются. Завершённые JFR-файлы сохраняются отдельно от кольца.

Снимок через PowerShell из корня `E:\servers_mew\skywars2_last`:

```powershell
$skywarsPid = (Get-NetTCPConnection -LocalPort 25566 -State Listen | Select-Object -First 1).OwningProcess
& .\runtime\jdk-25\bin\jcmd.exe $skywarsPid JFR.dump name=skywars-stalls 'filename=diagnostics/incident-%p-%t.jfr'
```

Команда сохраняет запись, не останавливая её. Выключение, если нужно:
`jcmd <PID> JFR.stop name=skywars-stalls`. При следующем запуске через
`start.bat` запись снова включится, пока его параметры не убраны.
