# Extra native gameplay carrier clone images ? 2 November 2026

Implementation only. No build/native process, installation, resource change or
skill exposure was performed by this owner task.

`CloneExtraAbilityStates` exposes recognizes, recognizesGameplay, protectedActor
and capture(game, entity). These carriers are real gameplay bodies; private class
names Visual/Display do not make them independent render children. The root native
image retains NBT, metadata, attributes, native runtime, identity, flags and spread.
Owner images preserve only each current actor and causal author, with no spending,
recasting, inventory ability duplication or whole checkpoint replay.

Babylon has exact BabylonArrow/BabylonTrident/BabylonRocket native factories and
independent live membership. Arrow transportAmp, blockEffectDone and retirement
state remain exact. The original native projectile owner stays external.

Stand has an exact FistDisplay factory retaining its original caster and source
level; a new Fist carries original epoch, direction, age and variant. Position is
the cloned native display position. Player retained Stand authority and burst
queues are not copied. A private constructor overload preserves the fixed source
level without depending on the caster's current dimension.

Sheep Hole uses the exact Body marker factory, original UUID author/cause/epoch/
level, current point/velocity and copied tilt. Point and independent erosion state
are translated by the actual native clone offset. BlackHoleErosion.copyTranslated
preserves only current cursor/seed/pass geometry, never past world changes. A new
BlackHoleVisuals handle is created once when its original author is resident in the
same dimension; ordinary owner lifecycle removes invalid/offline source actors.
Rollback removes only clone erosion, handle and registry state. Academy MagicSheep
is separately supported with its Converted record and exact factory: this is the
permanent nonplayer academy replacement, distinct from ordinary LbcPolymorph.
No player polymorph authority is copied.

God Hedgehog Actor Visual and RayBody factories now preserve independent kind,
point, direction and age. Their original external Encounter remains the causal
owner unless the copied family explicitly supplies its copied Boss encounter.
The white-arrow warning is regenerated once with the actual remaining charge time.
Warnings are packet-only TrialWarningVisual children, not native actor candidates.
Native Actor bodies are therefore no longer blanket protected by cloneProtected.

To prevent duplicate owner-image installation, God cloneRecognizes now covers only
its encounter/boss/blast branch; cloneActorRecognizes identifies these projectile
bodies for the extra dispatcher. Existing boss encounter image behavior is retained.
Laser queues are encounter work and are not replayed with a projectile clone.

Rollback removes clone registrations/visuals without explosions, rewards, source
cleanup or mutation of the original actor. Overall adapter coverage and exact
native qualification remain the root task responsibility.
