# Deferred TMT drafts

The author explicitly moved TMT to the final porting stage on1 November2026.
These files are incomplete reference drafts, OUTSIDE compilation/resources;
none is registered or installed. Do not report generator or activation parity.

- LbcTmtGenerator.java.draft: typed generator attempt, five Polymer carriers,
  source distributions and current registry pools. Not compiled/qualified.
- tmt_source.json: full literal legacy tables, extracted reproducibly by
  tools/extract_tmt_source.py. It is archival data, not a runtime resource.
- LbcTmtActivation.java.draft and LbcTmtSourceGroups.java.draft: partial explicit
  native-owner dispatch attempt, without full event/weapon coverage.
- activation-owner-deltas.patch: unapplied helper changes retained for reference.
  All related active owner files were restored to HEAD before final compilation.

Future design: catalogue actual useful item abilities by event after their owners
are ported; compose them through those owners without duplicated engines or a
function interpreter. Skip ineffective tags. Creation is never jammer-suppressed;
each ability follows its own already-agreed suppression rules. Preserve all legacy
generator families and uniformly include useful current registry entries.
