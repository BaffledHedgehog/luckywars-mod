## Scope correction and size

Neither AK47 nor Magnum is in **ordinary** `lbc:transformables_shooter`. Both are in `lbc/loot_table/transformables_shooter_all.json:7–64`: ordinary nested pool weight7, `lbc:stalin` weight1, Magnum weight1 (other entries follow).
