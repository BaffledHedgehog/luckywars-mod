Датированные `CURRENT`, `RUNNING`, `QUALIFIED` и `INSTALLED` описывают прошлые
этапы. Они не являются текущим заданием, активным процессом или подтверждением
установленной сборки. Предметные пользовательские контракты остаются справочником
с учётом последующих уточнений пользователя.

Текущие инструкции находятся в корневых [AGENTS](../../AGENTS.md),
[README](../../README.md), [ARCHITECTURE](../../ARCHITECTURE.md) и
[SERVER_TESTS](../../SERVER_TESTS.md). Упомянутые в старых материалах пути исходников
могут относиться к прежнему расположению классов; для навигации используйте имя
класса и актуальный поиск по Java-символам.
