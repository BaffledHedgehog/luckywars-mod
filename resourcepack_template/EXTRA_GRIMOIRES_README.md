# Дополнительные гримуары — 26 октября 2026

Сейчас добавлено 28 книг сверх исходных 240; достижение требует 268 книг.
Девять призывных гримуаров удалены по уточнению автора: призыватели не входят
в эту систему. Их ID 262–270 больше не используются.

Сохранены девять Tiny-книг, Бездушный (обычный и создание метасолы),
хэллоуинский ветер (обычный и три академических режима), Фартус, обычный
Gaycaster, Вечная мерзлота и Шиш-стена.
Добавлен также гримуар снежного жезла: `lbc:spelllib/snow`, ключи
`libspell_snow` и `libspell_snow.lore`, редкость Rare, tier D как у жезла.
Академическая версия создаёт облако в точке прицеливания: модель
`lbc:spelllib/snow_academy`, ключи `libspell_snow_academy` и `.lore`, tier B.

Добавлены семь академических книг Gaycaster: красный, оранжевый, жёлтый,
зелёный, голубой, синий и фиолетовый. Голубой использует электричество,
синий — воду, как в исходнике. Каждая книга одноразовая, не требует маны
и использует тот же обработчик, что соответствующий режим жезла.

Скопируй недостающие файлы с сохранением путей:

- `assets/lbc/items/spelllib/*.json` — определения предметных моделей;
- `assets/lbc/models/item/spelllib/*.json` — плоские модели книг;
- `assets/lbc/textures/item/spelllib/*.png` — места для новых текстур.

PNG — неизменённые копии существующей текстуры случайного гримуара.
Их можно перерисовать; генератор сохраняет уже существующие PNG.
Цветовые модели называются `gaycaster_red`, `gaycaster_orange`,
`gaycaster_yellow`, `gaycaster_green`, `gaycaster_cyan`, `gaycaster_blue`,
`gaycaster_purple` во всех трёх каталогах.

Ключи из `updates/extra_grimoires.ru_ru.json`, `.en_us.json` и `.rpr.json`
**объедини** с соответствующими `assets/minecraft/lang/*.json`.
Нельзя заменять ими полный файл языка. Уже применённые ключи не дублируются,
существующие авторские значения сохраняются. Ключи цветовых книг:
`libspell_gaycaster_<цвет>` и тот же ключ с `.lore`.

Список ID, исходных жезлов, tier и редкости:
[EXTRA_GRIMOIRES.json](EXTRA_GRIMOIRES.json).
Tier берётся у соответствующего жезла с учётом академического улучшения.
Цвета редкости: Base — серый, Rare — жёлтый, Epic — фиолетовый,
Legendary — красный; академические книги имеют приписку `enhanced`.

Авторский ресурспак агент не изменял. Оставшиеся в нём старые ресурсы
призывных книг можно удалить вручную: сервер их больше не выдаёт.
