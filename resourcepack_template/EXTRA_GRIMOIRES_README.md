# Новые гримуары — 26 октября 2026

Добавлен 21 гримуар, вся коллекция теперь состоит из 261 книги.

- Девять Tiny-жезлов: огонь, слепота, воздух, камень, телепортация, рубин,
  земля, кислота и электричество.
- Бездушный: обычное заклинание и академическое создание метасолы.
- Хэллоуинский ветер: обычное заклинание и три отдельных академических режима.
- Фартус, Gaycaster, Вечная мерзлота, Шиш-стена, призыв душ векса и Психовекс.

Обычные академические режимы Бездушного и ветра совпадают с неулучшенными
жезлами и используют ту же книгу. Все книги одноразовые и не требуют маны.

Скопируй новые файлы с сохранением путей:

- `assets/lbc/items/spelllib/*.json` — определения предметных моделей;
- `assets/lbc/models/item/spelllib/*.json` — плоские модели книг;
- `assets/lbc/textures/item/spelllib/*.png` — места для новых текстур.

PNG пока содержат **неизменённую копию существующей текстуры случайного
гримоара**. Их можно перерисовать; генератор не перезаписывает уже существующий
PNG. Имена файлов совпадают во всех трёх каталогах.

Ключи из `updates/extra_grimoires.ru_ru.json`, `.en_us.json` и `.rpr.json`
**объедини** с соответствующими `assets/minecraft/lang/*.json`. Эти небольшие
файлы содержат только новые ключи, ими нельзя заменять полный файл языка.

Список всех ID, исходных жезлов, tier и редкостей: [EXTRA_GRIMOIRES.json](EXTRA_GRIMOIRES.json).
Tier взят из эффективных компонентов соответствующего жезла, включая
академическое улучшение. Оформление редкости следует прежним гримуарам:
Base — серый, Rare — жёлтый, Epic — фиолетовый, Legendary — красный;
отдельные академические книги имеют прежнюю приписку `enhanced`.
Названия и описания подготовлены как заготовки для дальнейшей авторской правки.

Исходный авторский ресурспак агент не изменял.
