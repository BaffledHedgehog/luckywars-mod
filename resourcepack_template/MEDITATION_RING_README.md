# Кольцо каменной арены без пересечения секторов

Скопируй **все четыре файла вместе** из этого template в ресурспак по тем же
путям с заменой, затем нажми **F3+T**:

- `assets/lbc/models/item/meditation_warning_ring_green.json`
- `assets/minecraft/shaders/core/item.vsh`
- `assets/minecraft/shaders/core/item.fsh`
- `assets/lbc/shaders/include/meditation_warning.glsl`

Кольцо теперь вырезается шейдером на одной двусторонней плоскости вместо 96
перекрывающихся секторов. Края сглаживаются с учётом расстояния и наклона.
Из двух сторон модели в каждом ракурсе рисуется только обращённая к камере:
полупрозрачность не удваивается даже в проходе без отсечения обратных граней.

Сохранены зелёный цвет, прозрачность 0,55, затухание, радиусы 10–15 блоков и
серверное движение кольца. Оно остаётся равномерно освещённым и без тени.
Источник проблемы был в наложении геометрии: шейдер и раньше обходил освещение.

Модель и шейдеры нужно обновить вместе. Если заменить только модель, без нового
шейдера появится квадрат. Если заменить только шейдеры, старая модель из секторов
будет обрабатываться неправильно. Текстура и определение предмета остаются прежними.

Мод, серверную сборку и `bloom_sample.fsh` для этой правки менять не требуется.
Правки подготовлены из текущих файлов авторского пака; сам пак не редактировался.
Если core-шейдеры менялись после подготовки обновления, объедини следующие правки:

- `item.vsh`: дополнительный выход `vec2` в location13. Четыре последовательных
  индекса вершин нативной грани задают локальные углы плоскости независимо от UV
  атласа и разрешения текстуры.
- `item.fsh`: соответствующий вход. Только для прежнего точного маркера кольца
  RGBA `(43,216,147,252)` отсекается обратная грань и альфа умножается на маску кольца.
- `meditation_warning.glsl`: точное распознавание этого маркера и аналитическая
  маска с внутренним радиусом `1/3`, внешним `1/2` и сглаживанием через `fwidth`.

GPU-проверка: восемь вариантов item-шейдера скомпилированы и слинкованы; проверены
вид сверху/снизу и под наклоном, разные позиции в атласе и индексы граней,
однократный вклад прозрачности, неизменность освещения/затухания и остальных
материалов. Это проверка GPU, а не скриншот из игрового клиента.
