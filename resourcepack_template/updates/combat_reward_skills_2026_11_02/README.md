# Описания трёх навыков

Объединить записи из `ru_ru.json` и `en_us.json` с соответствующими файлами
`assets/minecraft/lang/` своего РП, заменив прежние значения этих ключей.
Это фрагменты, ими нельзя заменять весь языковой файл. Затем F3+T.

«Пулемётчик»: описан медленный рост залпа после разгона до залпа за тик;
в английском исправлена старая ошибочная экономия 90% на фактические 50%.
«Пожиратель душ»: описание соответствует положительным прибавкам сверх базы,
включая скорость атаки и базовое здоровье из настроек матча.
Описание «Развалился» менять не требуется.

Модели, шейдеры, звуки и оформление компонентов не меняются.
Исходный РП и основные файлы переводов template не изменены.
