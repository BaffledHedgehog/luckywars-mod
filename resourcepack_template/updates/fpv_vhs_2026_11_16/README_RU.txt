FPV-ДРОН: VHS-ПОМЕХИ

Скопируй assets из этой папки в свой ресурспак с заменой, затем нажми F3+T.
Меняется только assets/lbc/shaders/post/fpv_drone.fsh. Сборка мода для этого
дополнения не требуется. Авторский ресурспак при подготовке не изменялся.

На изображении с камеры дрона появляются зерно, слабые строки развёртки
и узкая проходящая полоса с горизонтальными срывами и смещением цветности.
Прежние боковые приборы сохранены. Помехи действуют только пока выбран
постэффект дрона. Буфер предыдущего кадра и дополнительные проходы не нужны.

Исходная альфа сохраняется. Служебные полосы данных камеры/чёрной дыры/
ядерных эффектов в левом верхнем и нижнем углу проходят без изменений RGB.

Для изменения интенсивности: коэффициент 0.036 задаёт зерно, 0.982 —
яркость чередующихся строк, а lineNoise * 5.0 + 2.0 — горизонтальные срывы.
Сила хроматического смещения — один пиксель внутри узкой полосы.

Проверки GPU/компилятора не заменяют просмотр на настоящем клиенте.
