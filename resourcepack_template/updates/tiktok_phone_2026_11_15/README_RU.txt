Телефон Admin Zaika: TikTok, ванильный экран и звук

Скопируй содержимое assets в свой ресурспак с объединением каталогов. В этой
версии дополнения обновлены не только переводы: нужны модель zaika_video,
экран, шейдер entity, include tiktok_pixels и звуки из assets/skywars2.
Исходный телефон lbc:zaika сохраняется. Видео показывается только от первого
лица; GUI, лежащий предмет и вид от третьего лица сохраняют исходную модель.

/skywars tiktok import — окно импорта cookies для оператора.
В ванильном текстовом поле максимум 20 000 символов из-за предела пакета
клиента. Для большого экспорта нажми «Импорт файла» и укажи путь к файлу на
компьютере сервера. Альтернатива:
  /skywars tiktok importfile "E:/папка/cookies.json"
Файл: UTF-8 JSON, до 4 МиБ; BOM, пробелы и переносы строк допустимы.
Чтение и проверка идут в фоне. Cookies сохраняются между перезапусками только
на сервере в config/skywars2/tiktok/cookies.json и не попадают в Git или чат.
/skywars tiktok status — состояние аккаунта и очереди.

ПКМ телефоном запускает видео, затем переключает на следующее. Скрытый кулдаун
5 секунд: при раннем ПКМ сообщение tiktok.loading красное, без курсива.
Сервер хранит до пяти оригиналов с производными; просмотренные удаляются после
освобождения читателей. Очередь берётся с «Для вас», без подмены общей лентой.

Ванильный клиент: экран 64×112, 20 FPS, передача цветами предмета; звук —
24 полосы огибающей, смешиваемые из 50-мс шумов, не более 8 звуков на кадр.
Это приближение звука. Необязательный мод для полноценного JPEG/PCM-стриминга
и большой вставки cookies частями ещё в работе. Пункт 43 пока не закрыт.
Временный предел подготовки — первые 5 минут; оригинал сохраняется полностью.
Этот предел требуется пересмотреть до завершения всей функции.

Зависимости сервера: Python 3.11+, numpy, Pillow, requests, Playwright,
yt-dlp, ffmpeg/ffprobe в PATH, установленный Chrome/Edge/Playwright Chromium.
Браузер автоматически не скачивается. Можно задать SKYWARS_TIKTOK_PYTHON
и SKYWARS_TIKTOK_BROWSER. Обработка ffmpeg однопоточная; подготовка по одному
видео. Лимиты диска: кэш 768 МиБ, отдельный оригинал 64 МиБ.

Один реальный ролик с «Для вас» успешно скачан и подготовлен с переданными
cookies. Проверки GPU выполнены вне Minecraft; просмотр и звук в подключённом
клиенте ещё требуется проверить. Автотесты не заменяют такую проверку.

Проверки:
  python tools/check_tiktok_worker.py
  python tools/check_tiktok_feed.py
  python tools/check_tiktok_phone_shader.py
На отдельном тестовом сервере:
  /skywars check tiktok-account
  /skywars check tiktok-bulk-import
  /skywars check tiktok-playback

PHONE_BASELINE — исходные шейдеры для сравнения в GPU-тесте; это не assets
и копировать их в ресурспак не нужно. AUDIO_BANK.json описывает банк шумов.
