TikTok: подготовка личной ленты «Для вас» (часть реализации, 15.11.2026)

В этом дополнении пока только новые переводы интерфейса импорта/очереди.
Скопируй assets в самостоятельный ресурспак. Исходный РП авторства не меняется.
Существующее оформление и пассивные свойства телефона остаются прежними.

Серверные команды (только оператор):
  /skywars tiktok import — нативное окно для JSON cookies tiktok.com.
  /skywars tiktok status — состояние аккаунта, число готовых видео и ошибка подготовки.

Cookies сохраняются в config/skywars2/tiktok/cookies.json. В диалог никогда не
возвращается сохранённое значение. Поддерживаются массивы cookies и объект
с полем cookies. Максимум 14000 символов обусловлен лимитом нативного ответа
диалога (32 КиБ NBT); экспортируй только домен tiktok.com.

Сервер хранит до пяти оригиналов и подготовленных вариантов в
<world>/data/luckywars/tiktok/videos. Подготовка выполняется последовательно
в отдельном процессе с одним потоком ffmpeg. Используется изолированный
браузерный контекст с импортированными cookies; запрашивается именно /foryou,
без подмены личной ленты общим списком популярных роликов. Старые видео
удаляются вместе с производными, когда их больше никто не использует.
Незавершённые рабочие папки удаляются при старте и после ошибки.

Зависимости сервера: Python 3.11+, numpy, Pillow, Playwright, yt-dlp, ffmpeg
и ffprobe в PATH. Браузер: установленный Edge, Chrome или уже установленный
Chromium Playwright. Дополнительный браузер автоматически не скачивается.
Можно задать SKYWARS_TIKTOK_PYTHON и SKYWARS_TIKTOK_BROWSER.

На этой машине зависимости проверены; браузерный тест использовал Chrome.
Доступ к настоящему аккаунту ещё не проверен. Полное воспроизведение телефона
(ванильный экран и звук, необязательный клиентский мод, определяемый при входе)
ещё в работе. Подготовленные форматы: 20 FPS, карта 64x112, JPEG 256x448,
PCM 24 кГц mono и 24 полосы огибающей для ванильного звука.
Текущий технический предел подготовки — первые 5 минут ролика, оригинал
сохраняется полностью; этот предел требуется пересмотреть до закрытия пункта43.
Кэш ограничен 768 МиБ, отдельный оригинал — 64 МиБ.

Проверки без аккаунта и без удалённых запросов страницы:
  python tools/check_tiktok_worker.py
  python tools/check_tiktok_feed.py
В изолированном тестовом сервере:
  /skywars check tiktok-account
