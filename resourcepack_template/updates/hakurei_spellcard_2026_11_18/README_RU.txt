В этом обновлении два шейдера меняют оттенок запасной стенки и подсветки
при соприкосновении зоны с поверхностью. Они подготовлены на основе файлов
all_in_one_1.21.8 с контрольными суммами из AUTHOR_BASE_SHA256.json.
Скопируй FSH-файлы по тем же путям внутри пака. Если исходник уже изменился,
перенеси значения RGB из этого обновления в свои версии.

Из en_us.json и ru_ru.json добавь два ключа lbc.hakurei.* в словари пака.
Они используются при объявлении спеллкарты жезла и бомбы Храма Хакурей.
