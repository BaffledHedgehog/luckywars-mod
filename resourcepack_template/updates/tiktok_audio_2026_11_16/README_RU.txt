Стереозвук телефона для ванильного клиента — 16 ноября

Скопируй assets/skywars2/sounds/tiktok/v3 целиком в основной ресурспак.
assets/skywars2/sounds.json содержит ТОЛЬКО новые ключи: объедини их
с существующим sounds.json. Не заменяй им основной файл целиком.
После применения перезагрузи ресурсы через F3+T.

Банк содержит 3552 коротких звука, около19МБ в OGG. Высокие частоты
сохраняются вместе с фазами исходного голоса. Стереоразница передаётся
отдельно; для моно исходников её бюджет используется на детали голоса.
Шумовые полосы предыдущего варианта к новому звуку не добавляются.

Нужна серверная сборка с поддержкой TKA1. Старые сохранённые видео
обновляют только подготовленную аудиодорожку в фоне: повторный импорт
cookies и скачивание исходных роликов не требуются. Старый v2 остаётся
резервным вариантом до завершения такого обновления.

Клиент с дополнительным media-модом продолжает получать исходный PCM.
Эта правка его поток не меняет.

Генератор: tools/build_tiktok_spectral_audio.py.
OGG можно воспроизвести заново из исходного кода; они исключены из Git.
AUDIO_BANK.json и export-manifest.json описывают проверенный банк.
Сама папка основного ресурспака генератором не изменяется.
