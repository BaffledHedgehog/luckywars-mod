Самостоятельный РП: палитра Polymer, 5 ноября 2026

Скопируй assets из этой папки в основной РП. Это дополнение, не отдельный
ресурс-пак. Служебные JSON вне assets нужны только для проверки соответствий.

note_block.json содержит 5 назначенных вариантов. Если в основном РП уже есть
свой note_block.json, объедини variants по ключам; остальные варианты сохрани.
В проверенном основном РП этого файла пока нет. Обычные нотные блоки продолжают
использовать ванильную модель, а грибные блоки это дополнение не меняет.
Модели трёх лаки-блоков берутся из уже существующих ресурсов основного РП.

После установки дополненного основного РП всем игрокам можно отключить
enabled в config/polymer/auto-host.json. Это выключает автоматическую раздачу
второго пака. Файл конфигурации здесь намеренно не изменён: пока дополнение
не перенесено в основной РП, клиенту ещё нужны генерируемые соответствия.
Polymer и его перевод серверных блоков/предметов в клиентские остаются нужны.

Назначения зависят от установленных модов, версии Polymer и набора блоков.
При их изменении заново экспортируй текущий polymer/resource_pack.zip:

python tools/export_block_palette.py --pack ../polymer/resource_pack.zip --reference-pack <основной_РП> --output <новая_папка_дополнения>

Инструмент читает основной РП, но никогда не пишет в него. Он экспортирует
палитру и её зависимости, не копируя старые переводы из JAR поверх твоих.
export-manifest.json фиксирует SHA-256 исходного ZIP и каждого файла.
