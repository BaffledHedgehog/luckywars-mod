Команды:
  /skywars settings ranked true
  /skywars settings synchroRanked true
  /skywars settings synchroRanked false

ranked сохраняет ограничения легаси на дроп и доступность перков.
synchroRanked — отдельная настройка, по умолчанию выключена. Новое значение
применяется со следующего матча. Для каждого пула на матч выбирается общий
случайный порядок. Каждый игрок проходит его самостоятельно: чужие открытия,
респавн и переподключение не сдвигают его очередь. Очереди разных пулов независимы.

Синхронизируются также случайные параметры предметов, TMT, значения плит и
содержимое стартовых сундуков одинакового типа/порядкового номера на разных
островах. Центральные сундуки остаются общими объектами карты. Безличный дроп
мира использует отдельную очередь; дроп мобов с известным автором — очередь автора.
Старые и новые имена одного uniform-пула используют одну очередь.

Личные условия допуска и модификаторы дропа сохраняются: одинаковые условия
дают одинаковый результат. Если перк меняет количество бросков, состав пула
или допустимость предмета, он продолжает это делать. Сами перки не отключаются.

На следующий матч создаётся новый порядок; при откате восстанавливаются и
позиции очередей. История ItemStack не накапливается — хранятся seed и счётчики.

Объедини assets с ресурспаком для перевода названия настройки.
