# Клиентское дополнение для телефона

Fabric, Minecraft 26.3, Java 25. Нужен Fabric API для этой версии игры.

Сборка из корня репозитория: `gradlew.bat -p media-client build`.
Готовый файл: `media-client/build/libs/skywars2-media-client-0.1.0.jar`.
Положить его в `mods` клиентского профиля и перезапустить клиент. На сервер этот JAR ставить не нужно.

При входе дополнение сообщает серверу свои возможности. Телефон показывает JPEG 720×1280,
20 кадров/с, со стереозвуком PCM 48 кГц. Ресурспак игры нужен для модели самого телефона.

При наличии FFmpeg и ffprobe клиент сначала загружает оригинальное MP4 напрямую с TikTok.
Если загрузка недоступна, используется HTTPS-сервер на Velocity. FFmpeg и ffprobe ищутся
в PATH; пути можно задать параметрами Java `-Dskywars2.media.ffmpeg=...` и `-Dskywars2.media.ffprobe=...`.
Эти программы необязательны: без них сервер передаёт подготовленное видео по HTTPS частями
до 40 кадров. Клиент держит текущую часть и одну следующую, не загружая весь длинный ролик заранее.
Разрешение и стереозвук сохраняются. Через игровое соединение в этом режиме идут только команды
управления воспроизведением. Cookies TikTok остаются на сервере.

Клиент и сервер согласуют поддержку частей автоматически. С прежним сервером или прежним
клиентским дополнением продолжает работать предыдущий протокол. Игроки без дополнения сохраняют
ванильный вариант: 480×854 и звук из банка шумов ресурспака.

ПКМ запускает следующее подготовленное видео. Между переключениями есть задержка 5 секунд.
Видео видно только владельцу от первого лица. При убирании телефона, смерти или выходе
загрузка и звук прекращаются. Временные файлы в `skywars2-phone-cache` удаляются при остановке
или смене видео; буферы в памяти ограничены. Остановка времени приостанавливает воспроизведение
и загрузку, после её завершения они продолжаются с сохранённой позиции.

Проверки в `build` покрывают геометрию экрана, порядок кадров и PCM, пятиминутный поток
свыше 64 МиБ частями, паузу и очистку, декодирование JPEG через STB, MP4 через FFmpeg
и очередь OpenAL на беззвучном тестовом устройстве. Проверка изображения и звука
в настоящем игровом окне остаётся отдельной ручной проверкой.
