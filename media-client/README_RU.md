# Клиентское дополнение для телефона

Fabric, Minecraft 26.3, Java 25. Нужен Fabric API для этой версии игры.

Собрать из корня репозитория: `gradlew.bat -p media-client build`.
Готовый файл: `media-client/build/libs/skywars2-media-client-0.1.0.jar`.
Положить его в `mods` клиентского профиля и перезапустить клиент. На сервер этот JAR ставить не нужно.

При входе дополнение объявляет поддержку протокола. Телефон автоматически получает
JPEG 720×1280, 20 кадров/с, и настоящий PCM-звук 48 кГц, стерео.
Игроки без дополнения сохраняют ванильный вариант: 480×854 и звук из банка шумов ресурспака.
Оригинальный ресурспак игры по-прежнему нужен для модели самого телефона.

ПКМ запускает следующее подготовленное видео; скрытая задержка между переключениями — 5 секунд.
Видео видно только владельцу от первого лица. При убирании телефона, смерти, выходе
или остановке времени поток и звук прекращаются. Локальных файлов видео и cookies
это дополнение не создаёт. Буферы в памяти ограничены и очищаются при остановке.

Проверки в `build`: тайминг и границы буфера, реальное декодирование JPEG через STB
в NativeImage и реальная очередь OpenAL на беззвучном тестовом устройстве.
Проверка на подключённом игровом клиенте остаётся отдельной ручной проверкой.
